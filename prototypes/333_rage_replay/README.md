# 333 — RAGE REPLAY

## 出典
game_idea_factory 2026-08-21 バッチ #2（Score 31.05 ハッキング/デッキ構築）のフック
「ダメージを与えると敵が強化される（逆転条件）」「ログ/リプレイが資産」を再解釈。
全10案がデッキ構築/ダイスに集中していたため、最も移転可能な「反転条件」フックを
弾幕回避ボス戦に再解釈（コレクション初のリバーサル/弾幕回避ジャンル）。

## 実行方法
```bash
cd ~/repos/game-prototypes
uv run python prototypes/333_rage_replay/main.py
```

## 操作
- ARROWS / WASD: 移動
- SPACE: 発射（自動照準）
- タイトル/ゲームオーバー: SPACE / ENTER で開始・再挑戦

## 体験仮説
「攻撃を当てるほどボスが強くなる」という反転条件の中で、自分の攻撃履歴が
そのまま弾幕になって返ってくるのをギリギリで縫って回避すると、攻め急ぎを
反省しつつ「次はレイジを管理しながら攻めよう」と思える。

## 実装したコアループ
1. 移動(ARROWS/WASD)でボスの照準弾を回避
2. SPACEで自動照準弾を発射し、ボスのHPを削る（当てるほどレイジ上昇+履歴記録）
3. レイジ100でエンレイジ（無敵化警告→履歴を扇形弾幕として撃ち返す→永続強化）
4. 60秒以内にボスHPを削り切れば勝利、HP0か時間切れで敗北

## うまくいっている点
- 攻撃が敵を強化する反転構造がシンプルに伝わる
- エンレイジ前の「トドメか、冷ますか」の駆け引きが毎回発生する
- リプレイ弾幕が「自分の攻めすぎ」を視覚的にフィードバックする

## 次に改善するなら最初に触る点
- エンレイジ中の照準弾も止めて「避けに専念」させる緊張と緩和を明確化
- リプレイ弾幕の形状（履歴の位置を反映した再現）を強める
