# ICE CARVE (306_ice_carve)

色付きの氷ブロックを削って傑作を作る、色合わせチゼル彫刻ゲーム。

## 体験仮説 (Experience hypothesis)
「同色の氷片を次々に削り出してコンボを伸ばし、SUPER CHISEL の虹色で一気にブロックを削って
スコアが爆発する快感」と「色を間違えると熱でブロックが溶け出し、溶けが隣接セルへ広がって素材を
失う緊張感」を両立させる。

## 実装したコアループ
1. 8×8 の氷片ボード（4色）をマウスクリックで削る。
2. ノミは最後に削った氷片の色を帯びる（プレイヤーが完全に色を制御する）。
3. 同色連続で COMBO（score = 10 × combo × 倍率）が伸び、COMBO>=4 で **SUPER CHISEL**
   （300f 虹色・任意色マッチ・スコア3倍・HEAT凍結・融解CA停止）が発動。
4. 色違いは HEAT+15・COMBOリセット・その氷片が MELTED（死セル）に。
5. 融解CA：各 MELTED セルが20%で直交隣接セル1つを溶かし、盤面が縮小していく。
6. HEAT>=100（MELTDOWN）または60秒でゲームオーバー → ENTER で即リスタート。

## リスクとリターン
- 同色連鎖を追う（欲張り）ほどスコア効率が高いが、同色の氷片を探して移動している間に
  融解CAが広がり素材を失う。
- ミスは COMBOリセットと盤面の永続縮小（MELTED化）を同時に引き起こすので失敗が複利で効く。

## うまくいっている点
- ノミ色 = 最後に削った色 という「常に定義される状態変数」で None バグを回避しつつ、
  プレイヤー主導の色制御（オート巡回ではない）を実現。
- 融解CA（スナップショット方式）で盤面縮小の空間的圧力を表現。
- HEAT のしきい値チェックを減衰の前に置く（decay-before-threshold バグ回避）。

## 次に改善するなら最初に触る点
- 彫刻の「完成形」の見せ方（シルエット目標や完成ボーナス）を追加して目的を明確化。
- 融解CAの難度カーブ調整（開始直後はほぼ広がらない猶予を確保）。
- サウンド（SE）の追加。

## 操作
- タイトル: ENTER または クリックでスタート
- ゲーム: マウスクリックで氷片を削る
- ゲームオーバー: ENTER でリトライ
