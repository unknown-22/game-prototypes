# SCANLINE — Baggage X-Ray Contraband Scanner

空港の手荷物X線検査官になり、ベルトコンベアを流れる荷物から危険物のシルエットを見抜く
部分観測ゲーム。**コレクション初のX線検査/危険物検出ジャンル**（323〜 のブレイクアウェイ
シリーズ継続。色合わせ・COMBO/HEAT方式を意図的に不使用）。

## 体験仮説

「速く流れる荷物の中から危険物だけを見抜く」という部分観測の判断に、誤検知と見逃しの
双方にペナルティがあることで、「怪しいものはFLAGすべきか、安全を優先して通すか」の
駆け引きを毎回迫られ、コンボが伸びるほど次の一袋が気持ちよくなる。

## 面白い瞬間（一番面白いのは何か）

ベルトが加速してシルエットが流れていく中、ごちゃごちゃした荷物の隙間から銃や刃物の
シルエットを見つけ出し、出口すれすれでFLAGを叩いてコンボを伸ばす瞬間。

## 実装したコアループ

1. 荷物が左から右へ流れる（時間とともに加速）
2. 荷物の中身（2〜5個のシルエット）を見る → 危険物か判断する
3. クリックでFLAG（トグル）を付ける／付けない
4. 荷物が出口（右端）に到達した時点で判定：
   - FLAG＋危険物 = **CAUGHT**（+100×コンボ倍率、コンボ+1）
   - FLAG＋安全 = **FALSE ALARM**（コンボ消失、セキュリティ-10）
   - 素通し＋危険物 = **MISS**（コンボ消失、セキュリティ-15）
   - 素通し＋安全 = **PASS**（+20、コンボ+1）
5. セキュリティ0で SECURITY BREACH、90秒経過で SHIFT COMPLETE
6. 即リスタート（SPACE）→ 前回スコアと比較して再挑戦

## リスクとリターン

- **FLAGを積極的に打つ** = コンボ倍率（最大4倍）で高得点を狙えるが、誤検知でセキュリティが減る
- **素通しを優先する** = 誤検知は防げるが、見逃し（-15）のリスクが上がる
- どちらの失敗もコンボを消失させるため、「怪しい」荷物に対して毎回判断を迫られる

## 難度上昇（4ノブ）

| 要素 | 開始 | 終了（90秒時点） |
|---|---|---|
| 出現間隔 `spawn_interval` | 90f | 28f |
| ベルト速度 `bag_speed` | 1.0 px/f | 3.2 px/f |
| 荷物あたりの品数 `max_items` | 2 | 5 |
| 危険物混入率 `contraband_chance` | 30% | 55% |

## 操作方法

- **クリック**：荷物にFLAGを付ける／外す（トグル）
- **SPACE / ENTER**：タイトル開始・ゲームオーバー後のリスタート

- Pyxel 2.x、320×240（display_scale=2、60fps）

## うまくいっている点

- 判定がシンプル（FLAG×危険物の2×2）なので初回で即理解できる
- コンボ倍率とセキュリティ減算の両輪で「攻める/守る」の選択に意味がある
- 難度4ノブがすべて純関数で、時間経過が滑らかに体感できる

## 次に改善するなら最初に触る点

- **微妙な危険物（KNIFE/BOTTLE）の見えやすさ調整**：現在シルエットは色だけで識別。
  実物らしい形（銃身の角度、刃の反り）を強調して「見つける楽しさ」を強化する
- **荷物が5個でバッグ幅（64px）を超える描画**：アイテムセル（14px×5=70px）が袋から
  はみ出す。アイテムサイズを品数に応じて縮小するか、バッグ幅を可変にする
- **「疑わしいが確信がない」荷物向けの追加アクション**：ズーム（時間を消費して拡大確認）
  を入れると部分観測の緊張がさらに深まる
