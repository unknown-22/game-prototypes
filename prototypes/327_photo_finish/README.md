# PHOTO FINISH — Horse Racing Value Betting (Pari-Mutuel)

**Source idea**: game_idea_factory batch 2026-08-20, idea #1 (Score 31.4, "配送/物流（流量最適化）"
ヴァンサバ亜種) — reinterpreting its transferable hooks ("ログ/リプレイが資産", "連鎖崩壊") into a
fresh genre, following the 323–326 breakaway series that deliberately abandons the saturated
color-match COMBO/HEAT formula.

## 体験仮説 (Experience hypothesis)

「オッズと隠れた実力のズレ（割安な大穴）を見抜いて賭け、レースのゴール直前で逆転する」とき、
「見抜けた」という知的満足と「本当に勝つか」という緊張が同時に味わえる。

## 実装したコアループ

1. **PADDOCK**（観察・賭け）: 5頭それぞれに隠れた実力 `form` と公開オッズ `odds`。
   オッズは実力を完全には反映しない（ミスプライス）。フォームゲージ `[gauge_lo, gauge_hi]`
   が時間とともに実力へ狭まり、同時にオッズが真の値へ補正される。
2. **賭けの判断**: 馬を選び（LEFT/RIGHT）、賭け金を調整（UP/DOWN）、SPACEでロック。
   **早くロック**＝ミスプライスされた割高オッズを確保（ただし盲撃ち）、
   **遅くロック**＝フォームを読み切れる（ただしオッズが補正され価値が消える）。
3. **RACE**（実況）: 実力+ノイズ `race_speed = form + U(-spread, +spread)` で馬が走り、
   最初にゴールした馬が勝つ。番狂わせが起こる。
4. **RESULT**: 勝てば `bankroll += stake × odds`、負ければ没収。即時再レース。

## リスクとリターン

- 本命（低オッズ）＝安全だが儲けが薄い / 大穴（高オッズ）＝危険だが大儲け。
- フォームゲージの部分観測＋オッズ補正が「早く賭けるか、じっくり観るか」のジレンマを生む。
- 実力+ノイズのレースにより、正しいバリュー賭けでも確率的に負ける（長期の期待値で勝つ）。

## 操作方法

| キー | 動作 |
|---|---|
| LEFT / RIGHT (A / D) | 馬を選ぶ |
| UP / DOWN (W / S) | 賭け金を増減（$50刻み, $50〜$1000） |
| SPACE / ENTER | 賭けをロックしてレース開始 |
| SPACE / ENTER (タイトル/ゲームオーバー) | 開始 / リスタート |

## 失敗条件とスコア

- 残高 < $50 → **BANKRUPT**
- 60秒経過 → **TIME UP**
- スコア = 最終残高（セッション内ベスト残高も記録）

## うまくいっている点

- 色合わせ・コンボ・HEAT を完全に排除した、純粋な「部分観測 × バリュー賭け」。
- オッズ補正が「早ロック vs 遅ロック」のトレードオフを数値で成立させている。

## 次に改善するなら最初に触る点
