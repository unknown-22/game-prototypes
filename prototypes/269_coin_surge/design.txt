COIN SURGE — Grid Coin Pusher (Prototype 269)
================================================

CONCEPT:
A side-view arcade coin pusher game on a grid. Player drops colored coins 
from the top of columns. Coins stack up. A periodic "pusher" shifts all 
coins rightward. Coins falling off the right edge are collected for points.
Same-color consecutive collections build a COMBO chain → SUPER DROP super mode.

CORE MECHANIC:
"Split into multiple paths → converge → explode" reinterpreted as:
  - Coins SPLIT across columns (player chooses where to drop)
  - Pusher CONVERGES them toward the right edge
  - Chain of same-color coins falling off = COMBO EXPLOSION

PHASE MACHINE:
  Phase enum: TITLE, PLAYING, PUSHER_ANIM, COLLECT, GAME_OVER

  TITLE: Show title + controls, press SPACE/click to start
  PLAYING: Main game loop
    - Player clicks a column to drop a coin OR presses number keys 0-9
    - Coin spawns at top of column, falls due to gravity
    - Timer counts down from 60s (1800 frames)
    - Pusher activates every PUSHER_INTERVAL frames
    - When pusher fires → transition to PUSHER_ANIM
  PUSHER_ANIM: Animate coins shifting right (15 frames)
    - After animation → transition to COLLECT
  COLLECT: Evaluate coins in rightmost column
    - Coins at col 9 (last column) get pushed off → collected
    - Compute COMBO, score, HEAT
    - Spawn particles, floating text
    - Transition back to PLAYING
  GAME_OVER: Show final score, press SPACE to restart

  def _update_heat(self) -> None:
      """Decay heat, check game over. CHECK BEFORE decaying."""
      if self.heat >= HEAT_MAX:
          self.phase = Phase.GAME_OVER
          return
      self.heat = max(0, self.heat - HEAT_DECAY)

  def _update_super(self) -> None:
      """Decrement super_timer, deactivate when expired."""
      if self.super_mode:
          self.super_timer -= 1
          if self.super_timer <= 0:
              self.super_mode = False
              self.super_timer = 0

  def _update_timer(self) -> None:
      """Decrement timer, game over if 0."""
      self.timer -= 1
      if self.timer <= 0:
          self.phase = Phase.GAME_OVER

  def _update_color_cycle(self) -> None:
      """Cycle player drop color on timer."""
      self.drop_color_timer -= 1
      if self.drop_color_timer <= 0:
          self.drop_color = (self.drop_color + 1) % 4
          self.drop_color_timer = self.color_cycle_interval
      # Escalate color cycle interval over time
      if self.frame % 300 == 0 and self.color_cycle_interval > MIN_COLOR_CYCLE:
          self.color_cycle_interval -= 2

  def _update_difficulty(self) -> None:
      """Escalate pusher interval over time."""
      if self.frame > 0 and self.frame % 300 == 0 and self.pusher_interval > MIN_PUSHER_INTERVAL:
          self.pusher_interval -= 4

  def _spawn_particles(self, x: float, y: float, color: int, count: int) -> None:
      """Spawn count particles at position with random velocities."""
      import math, random
      for _ in range(count):
          angle = self._rng.random() * 2 * math.pi
          speed = 0.5 + self._rng.random() * 2.0
          self.particles.append(Particle(
              x=x, y=y,
              vx=math.cos(angle) * speed,
              vy=math.sin(angle) * speed - 1.0,
              color=color, life=20 + self._rng.randint(0, 10)
          ))

  def _spawn_floating_text(self, x: float, y: float, text: str, color: int) -> None:
      """Spawn floating score text."""
      self.floating_texts.append(FloatingText(x=x, y=y, text=text, color=color, life=30))

  def _update_particles(self) -> None:
      """Update particle positions and lifetimes."""
      for p in self.particles:
          p.x += p.vx
          p.y += p.vy
          p.vy += 0.05  # gravity
          p.life -= 1
      self.particles = [p for p in self.particles if p.life > 0]

  def _update_floating_texts(self) -> None:
      """Update floating text positions and lifetimes."""
      for ft in self.floating_texts:
          ft.y -= 0.5  # float upward
          ft.life -= 1
      self.floating_texts = [ft for ft in self.floating_texts if ft.life > 0]

  def _is_cell_occupied(self, col: int, row: int) -> bool:
      """Check if a grid cell has a non-falling coin."""
      # Ignore falling coins (they're in transit)
      return any(c.col == col and c.row == row and not c.falling for c in self.coins)

  def _get_coin_at(self, col: int, row: int) -> Coin | None:
      """Get non-falling coin at grid position."""
      for c in self.coins:
          if c.col == col and c.row == row and not c.falling:
              return c
      return None

UPDATE LOOP (PLAYING phase):
  self._frame_count += 1
  self.frame += 1  # total frame counter
  self._update_timer()  # CHECK BEFORE incrementing frame to avoid off-by-one
  # Actually: timer decrement after frame increment
  if self.frame % GRAVITY_INTERVAL == 0:
      self._apply_gravity()
  self.pusher_countdown -= 1
  if self.pusher_countdown <= 0:
      self.phase = Phase.PUSHER_ANIM
      self._anim_frame = 0
      self._pending_collected = self._activate_pusher()
      self.pusher_countdown = self.pusher_interval
  self._update_color_cycle()
  self._update_difficulty()
  self._update_heat()
  self._update_super()
  self._update_particles()
  self._update_floating_texts()
  # Timer check: do this last
  if self.timer <= 0:
      self.phase = Phase.GAME_OVER
      self.best_score = max(self.best_score, self.score)

UPDATE LOOP (PUSHER_ANIM):
  self._anim_frame += 1
  self._update_particles()
  self._update_floating_texts()
  if self._anim_frame >= PUSHER_ANIM_FRAMES:
      self.phase = Phase.COLLECT

UPDATE LOOP (COLLECT):
  self._evaluate_collection(self._pending_collected)
  self._pending_collected = []
  self.phase = Phase.PLAYING

  - All 10 columns full: player can't drop, but pusher will create space
  - No coins to push: pusher fires but nothing happens (no crash)
  - Super mode ends mid-collection: active for the entire COLLECT phase
  - Heat reaches exactly 100: game over
  - Timer reaches 0 during PUSHER_ANIM: game over after anim completes
  - First coin collected: always matches (combo=1, no mismatch heat)
