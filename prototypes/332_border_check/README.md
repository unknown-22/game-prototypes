# 332_border_check — 国境審査官（Border Check）

国境の入国審査官になり、次々に訪れる旅行者の書類を「変わり続けるルールブック」と照合して
**入国許可（APPROVE）** か **入国拒否（DENY）** を下す、判断力ゲーム。

「Papers, Please」系の **書類審査** ジャンルはコレクション初。
既存の大量の color-match COMBO/HEAT 系とは違い、**色合わせ・コンボ・ヒートのいずれも使わない**
（323〜331 の「脱コンボ」シリーズを継承した、純粋な意思決定プロトタイプ）。

## 体験仮説

「迫る忍耐ゲージの中で、期限切れビザ・指名手配・申告超過を見抜いて **DENY** を叩き、
連続正解のストリークを伸ばすと気持ちいい」—— 走査の集中と『見つけた！』の快感を起こしたい。

## 実装したコアループ

1. **見る** — 上段のルールブック（3件、うち1件が近々差し替え）と、中央の旅行者カード
   （名前・出身国・ビザ種別・残日数・申告額）を読む
2. **判断する** — ルールを1つでも違反していれば DENY、全てクリアなら APPROVE
3. **操作する** — A/←（承認）・ D/→（拒否）または画面上のボタンをクリック
4. **結果** — 正解ならストリーク＋得点（素早い判断は +25 の QUICK ボーナス）、
   誤審はライフ−1、遅すぎると MISS（忍耐ゲージ切れ）

- ルールは約12秒→7秒ごとに1件だけ差し替わる（**「各フロアでルールが1つだけ変わる」**フックの転用）
- 難度は2ノブ：忍耐の初期値 300→150f、ルール差し替え間隔 720→420f
- 失敗：ライフ0（DETAINED）or 60秒経過（SHIFT OVER）

## リスクとリターン

- **速く裁くほど得点効率が高い**（QUICK ボーナス、ストリーク倍率 最大5倍）が、誤審でライフを失う
- **じっくり確認すれば安全**だが、忍耐ゲージが切れると MISS でストリークが消える
- ルール差し替えの予告（黄色点滅＋「!」）を読むか、目先の審査に集中するかの駆け引き

## 操作方法

| キー | 動作 |
|---|---|
| A / ← | 入国許可（APPROVE） |
| D / → | 入国拒否（DENY） |
| マウス左クリック | 緑＝APPROVE ボタン / 赤＝DENY ボタン |
| SPACE / R / RETURN | スタート・リトライ |

## 技術

- Python 3.12 / Pyxel 2.x / 320×240 / 60fps
- ロジックは Pyxel 依存から分離（`rule_violated`・`traveler_is_denied`・`score_correct`・
  `patience_start`・`rule_interval` はモジュールレベルの純関数）
- `Game.__new__(Game)` + シード済み RNG 注入でヘッドレステスト可能
- ruff / ty / pytest すべて通過（23 headless tests）

## 次に改善するなら最初に触る点

- **判定の歯応え**：現状はルール違反が単純な数値比較なので、慣れると一瞬で解ける。
  書類の一部を「にじませる（部分観測）」か、値が閾値ギリギリ（例：ビザ残29日 vs 30日未満拒否）の
  敵対的サンプルを混ぜると走査の緊張が長持ちする。
- **誤審の見える化**：なぜ誤審だったかをゲームオーバー画面で復習できると学びにつながる。
