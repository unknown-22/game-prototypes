# TICKER SURGE — 株式デイトレード・タイミングゲーム

コレクション初の **株式市場 / デイトレード** ジャンル。既存の「同色コンボ → SUPER モード + HEAT」という飽和した定型から意図的に脱却し、色合わせではなく「相場のタイミングを読む」認知スキルを核に据えた。

## 体験仮説（1文）

「バブルメーターが危険を見える化する中で、急騰をギリギリまで握って天井手前で売り抜けられると『賢く勝った』感覚が生まれる」

## メカニクス仮説（MDA）

- **Mechanics（ルール）**: 単一の資産価格が BULL（上昇）/BEAR（下降）を往復する。BULL 中は BUBBLE メーターが溜まり、満タンになると「CRASH WARNING」が点滅した後に暴落。SPACE で BUY（全力買い）、B で SELL（全力売り）。
- **Dynamics（駆け引き）**: バブルが高いほど暴落が近い＝売るべき。だが警告中も価格は上がり続けるので、売りが早すぎると上昇を取り逃す。握るか逃げるかの判断が毎サイクル発生する。
- **Aesthetics（面白さ）**: 暴落前の天井で売り抜ける緊張と、+$ の緑文字が弾ける快感。

## 実装したコアループ

1. 価格チャート（下部80pxに折れ線、上昇=緑/下降=赤）と BUBBLE メーター（右側、黄→橙→赤）を見る
2. 底値で BUY、バブルが溜まったら SELL のタイミングを判断
3. 売却益（cost_basis との差額）が即時 +$ 表示で返る
4. 60秒で残高（cash + shares×price）を最大化する

## ゲームルール

- 開始資金 $1000、価格 $100、60秒（3600フレーム）
- **BUY**（SPACE / ボタン）: 現金で買えるだけ全量買い
- **SELL**（B / ボタン）: 全量売却、損益を確定
- **価格モデル**: トレンド（±）+ ノイズ + **平均回帰**（START_PRICE へ引き戻す力）で、価格はおよそ $40〜$200 のレンジを推移
- **BUBBLE メーター**: BULL で 0.9/f 溜まり、BEAR で 0.7/f 減る。満タン(100)で CRASH WARNING → 暴落（BEAR へ反転）
- **失敗条件**: ① 残高が $400 未満 = MARGIN CALL、② 60秒経過 = TIME UP
- **スコア**: 最終残高（cash + shares×price）。best_score は永続

## リスクとリターン

- 警告中も価格は上昇し続ける → 早く売ると上昇を取り逃す（安全側の機会損失）
- 警告を無視して握ると暴落で含み益が吹き飛ぶ（欲張りの損）
- 暴落後の底値圏で買うと回復相場の上昇を丸ごと取れる

## 操作

| キー | 動作 |
|---|---|
| SPACE / クリック | BUY（全力買い） |
| B / クリック | SELL（全力売り） |
| ENTER | タイトルから開始 |
| R | ゲームオーバーからリスタート |

## うまくいっている点

- バブルメーターが「危険の見える化」として機能し、理不尽でない失敗（=売り遅れ）が原因を説明できる
- 平均回帰により価格がレンジ内に収まり、60秒で複数サイクル（約10回）の売買判断が発生する
- cost_basis を導入し、売却時の +$/-$ が正確な損益を即時フィードバックする

## 次に改善するなら最初に触る点
