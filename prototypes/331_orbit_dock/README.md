# SPACE DOCK — Orbital Traffic Control (331)

**Source**: Reinterpreted from game_idea_factory idea #2 (Score 31.8, 宇宙採掘/デッキ構築ローグライト).
Hooks carried over: 「ログ/リプレイが資産」→ レーダー上の航跡トレイル、 「ヒット数/チェイン数が画面全体で可視化・加速」→ ドッキング数/ニアミスカウンタ。

**Engine**: Pyxel 2.x, 320×240 @ 60fps.

## 体験仮説 (Experience hypothesis)
60秒の時間制限の中で、いま操作していない宇宙船が勝手に流され続ける危険を抱えながら、
「どの船を先に救うか」を判断し、すれすれで衝突を避けて次々とドッキングさせたい。

## 一番面白い瞬間
ギリギリまで航路を詰めて、衝突しそうな宇宙船をすれすれで避けながら次々とドッキングさせる瞬間。

## コアループ (implemented)
1. 宇宙船が画面端からランダムな方位・速度で進入する。
2. クリックで1隻を選択（黄ハイライト）。←→で針路、↑↓でスロットル。
3. 選択していない船は現在の針路・速度で流れ続ける（無視するほど危険）。
4. 船がベイ内かつ低速ならドッキング成立（スコア＝残燃料が多いほど高得点）。
5. 衝突＝両船喪失＋ライフ-1。燃料切れ＝漂流＋ライフ-1。ニアミス＝+20点ボーナス。
6. ライフ0（ALL SHIPS LOST）か60秒（TIME UP）でゲームオーバー。

## リスクとリターン
- **スロットルを上げる**＝早く着けるが制御が難しく衝突しやすい／**下げる**＝安全だが燃料を食う。
- **詰めて処理する**＝スループット(スコア)が伸びるが衝突リスクが上がる。
- ニアミス(+20)は衝突すれすれの距離に自ら踏み込むことで得られる報酬。

## 操作方法
- タイトル/ゲームオーバー: ENTER or SPACE で開始/再挑戦
- ゲーム中: クリックで船を選択、←→ = 針路、↑↓ = スロットル、ESC = 即終了
