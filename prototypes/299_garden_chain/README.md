# GARDEN CHAIN (299_garden_chain)

色合わせ COMBO チェイン型ガーデニング / 植物育成プロトタイプ。
コレクション初の「ガーデニング / 植物育成」ジャンル。

## Source
- Reinterpreted from `game_idea_factory` idea #1 (Score 31.45) — 宇宙採掘デッキ構築
  - フック「盤面がセルオートマトン（感染/増殖）で埋まっていくのを制御する」→ 植物が CA で発芽・増殖
  - フック「合成/圧縮」→ 同色連続収穫 COMBO → SUPER HARVEST（虹色モード）
- 全 10 案がデッキ構築/オートシューター/ダイスに偏ったため、未踏ジャンルへ再解釈した。

## 体験仮説
増え続ける庭で、同色の大きな塊（クラスタ）を見極めて一気に収穫し、COMBO 連鎖と
SUPER HARVEST の虹色モードで次々と刈り取る快感を味わわせたい。

## Engine / Screen
- Pyxel 2.x, 320×240, display_scale=2, 60fps
- グリッド 10×8, CELL=24px（プレイフィールド 240×192、オフセット (40, 24)）

## Gameplay / Core Loop
1. 土のグリッドに 4 色の植物（RED/LIME/DARK_BLUE/YELLOW）が生えている。
2. 植物は生きている：
   - **SPROUT**（発芽）: 一定間隔でランダムな空きセルに新たな種が生える。
   - **SPREAD**（CA 増殖）: 一定間隔で各植物が隣接する空きセルへ同色で広がる。
   - → 盤面は放っておくとどんどん埋まっていく。
3. プレイヤーはクリックで植物を収穫する。クリックしたセルと同じ色の
   直交連結クラスタ（BFS）をまとめて収穫し、植物数 × 10 × COMBO のスコアを得る。
4. **同色を連続で収穫**すると COMBO が伸びる（倍率アップ）。
5. 違う色を収穫すると COMBO リセット + HEAT +15。空き土をクリックするとミス
   （HEAT +5、COMBO リセット）。
6. COMBO ≥ 4 で **SUPER HARVEST**（300 フレーム）: どの色でもマッチ、スコア ×3、
   虹色ボーダー。自由にクラスタを刈り取れる。
7. **リスク**: 庭が過密（占有 ≥ 閾値）になると毎フレーム HEAT 上昇。HEAT 100 で
   ゲームオーバー。60 秒タイマー切れでもゲームオーバー。

### 判断（リスクとリターン）
- 今すぐ収穫するか（安全、盤面を空ける）／大きくなるまで待つか（1 クリックで
  大量得点）を選ぶ。ただし待つと庭が過密化し、同色が尽きると COMBO 断絶のリスク。
- 同色を追い続けるか（COMBO 継続・高倍率）／別色に切り替えるか（COMBO 断絶 + HEAT）を選ぶ。

## Controls
- タイトル: クリック / SPACE / RETURN で開始
- ゲーム: マウスクリックでクラスタ収穫
- ゲームオーバー: SPACE / RETURN で即リスタート
- ESC: 終了
