# SEW CHAIN — Tailor / Sewing color-match COMBO chain prototype

## Experience hypothesis (Japanese for the manifest)
「針の色が合う布パッチを次々に縫ってCOMBOを伸ばし、SUPER STITCHの虹色で一気に縫い上げる快感。ただし糸は有限で、尽きると縫えない。糸を巻き直す(RETHREAD)タイミング＝安全な色巡回の隙を狙う駆け引きが生まれる」

## "Most fun moment" (one sentence)
Same-color fabric patches sewn consecutively build a COMBO that explodes into a rainbow SUPER STITCH, while a finite THREAD spool forces a "re-thread now (safe) vs keep stitching (greedy)" decision.

## Core mechanic (ONE mechanic, distinct from the collection)
A **finite THREAD spool** as a second resource. Every successful sew consumes 1 thread. At 0 thread you CANNOT sew. Press R to RETHREAD: a short 120-frame "threading" pause that restores THREAD to max, resets COMBO, and adds +5 HEAT. This is a strategic "hold vs spend now" decision on top of the standard color-match COMBO chain → SUPER formula. First sewing/tailor genre in the collection.

## Requirements (follow EXACTLY)

### Screen & engine
- Pyxel 2.x, 320x240, 60fps (display_scale handled by caller)
- `import pyxel` directly at top (NO TYPE_CHECKING guard)

### Color constants (raw ints — use these exact values)
- BLACK=0 NAVY=1 PURPLE=2 GREEN=3 BROWN=4 DARK_BLUE=5 LIGHT_BLUE=6 WHITE=7 RED=8 ORANGE=9 YELLOW=10 LIME=11 CYAN=12 GRAY=13 PINK=14 PEACH=15
- 4 fabric colors: RED=8, LIME=11, DARK_BLUE=5, YELLOW=10
- Use these ints directly in a module-level tuple `FABRIC_COLORS: tuple[int, ...] = (8, 11, 5, 10)`

### Entities (dataclasses with type hints)
- `Patch`: dataclass — `color: int`, `x: int`, `y: int`, `respawn_timer: int` (0 = alive/visible; >0 = dead, counting down to respawn). 8 patches in a fixed horizontal row.
- `Particle`: dataclass — `x: float`, `y: float`, `vx: float`, `vy: float`, `life: int`, `color: int`
- `FloatingText`: dataclass — `x: int`, `y: int`, `text: str`, `life: int`, `color: int`

### Layout
- 8 patches in a single horizontal row. Patch size 24x24. y = 110 (patches centered horizontally: x = 16 + i*36 for i in 0..7 → spans 16..268, fits 320 width). Draw each patch as a filled rect + white border. The active patch under the needle is NOT positional — any patch can be clicked.
- Needle indicator drawn at top (a vertical needle + thread line) with its current color shown as a colored circle at (160, 60).

### Phase enum
```
class Phase(Enum):
    TITLE = auto()
    PLAYING = auto()
    RETHREADING = auto()   # the 120f threading pause
    GAME_OVER = auto()
```

### Core state (instance attributes, initialized in reset())
- `score: int = 0`, `combo: int = 0`, `max_combo: int = 0`
- `heat: float = 0.0` (cap HEAT_MAX=100 → game over "NEEDLE SNAPPED")
- `thread: int = THREAD_MAX` (THREAD_MAX=12)
- `needle_color: int` (index into FABRIC_COLORS, starts 0)
- `needle_timer: int = 0` (auto-cycle: counts frames, advance color every `_cycle_interval()` frames)
- `timer: int = 3600` (60s at 60fps; on 0 → game over "TIME UP")
- `elapsed: int = 0` (frames since start, drives difficulty escalation)
- `super_timer: int = 0` (>0 = SUPER STITCH active, rainbow needle, any-color match, 3x score, heat frozen, thread NOT consumed)
- `rethread_timer: int = 0` (counts down the RETHREADING pause)
- `patches: list[Patch]`, `particles: list[Particle]`, `floats: list[FloatingText]`
- `shake: int = 0` (screen shake frames)
- `best_score: int = 0`
- `_rng: random.Random` (seed 42 — but see PITFALL note below)
- `frame: int = 0`

### Class-level constants
- `SCREEN_W = 320`, `SCREEN_H = 240`, `HEAT_MAX = 100`, `THREAD_MAX = 12`, `SUPER_DURATION = 300`, `RETHREAD_DURATION = 120`, `GAME_TIME = 3600`
- `MATCH_PARTICLES = 8`, `SUPER_PARTICLES = 20`, `MISMATCH_PARTICLES = 4`, `RETHREAD_PARTICLES = 12`

### Difficulty escalation (pure functions so they're testable)
- `_cycle_interval(self) -> int`: `max(12, 20 - self.elapsed // 120)` (20f→12f over 60s)
- `_respawn_delay(self) -> int`: `max(25, 60 - self.elapsed // 100)`
- `_heat_decay(self) -> float`: `-0.02` (frozen in SUPER and RETHREADING)

### Core methods (all headless-testable — DO NOT call pyxel.btn/btnp/mouse inside these)

- `reset(self)`: zero all state, build the 8 patches with random colors from `self._rng`, set `needle_color=0`, `thread=THREAD_MAX`, `phase=Phase.TITLE` (caller moves to PLAYING). CRITICAL: assign `self._rng = random.Random(42)` at the TOP of reset() before any helper that consumes it.
- `_sew(self, index: int) -> tuple[bool, str]`: the core action. If `self.thread <= 0` → return (False, "NO THREAD") (no state change). If patch dead (respawn_timer>0) → return (False, ""). Determine match: `matched = (patch.color == self.needle_color) or (self.super_timer > 0)`. If matched: combo += 1; max_combo = max(...); mult = 3 if super else 1; score += 10 * combo * mult; thread -= 1; patch dead (respawn_timer = self._respawn_delay()); spawn match particles + floating text; if combo >= 4 and super_timer == 0: super_timer = SUPER_DURATION + spawn SUPER burst + floating "SUPER STITCH!". If NOT matched: heat += 15; combo = 0; thread -= 1 (wasted); spawn mismatch particles + "WRONG!" text + shake. Return (matched, "...").
- `_rethread(self) -> bool`: if `phase == Phase.PLAYING` and `thread < THREAD_MAX`: set phase=RETHREADING, rethread_timer=RETHREAD_DURATION, return True. Else False.
- `_finish_rethread(self)`: called when rethread_timer hits 0 — thread = THREAD_MAX; combo = 0; heat += 5; phase = PLAYING; spawn rethread particles + "RETHREADED" text.
- `_update_heat(self)`: CHECK THRESHOLD FIRST: `if self.heat >= HEAT_MAX: self.phase = Phase.GAME_OVER; return`. Then if super_timer==0 and phase != RETHREADING: `self.heat = max(0.0, self.heat + self._heat_decay())`. (Do NOT decay before the check — see PITFALL.)
- `_update_needle(self)`: needle_timer += 1; if needle_timer >= self._cycle_interval(): needle_timer = 0; needle_color = (needle_color + 1) % 4. (Skip advance while RETHREADING.)
- `_update_patches(self)`: for each dead patch, decrement respawn_timer; when it hits 0, assign a new random color (from _rng) and set alive.
- `_update_floats(self)`: decrement life, remove when <=0. `_update_particles(self)`: move by velocity, decrement life, remove when <=0.

### Rendering (only these touch pyxel draw calls)
- `draw()`: route by phase → `_draw_title()`, `_draw_playing()` (patches, needle color circle, thread spool bar, HEAT bar, timer bar, combo, score, particles, floats, shake via `pyxel.camera`), `_draw_game_over()`.
- Title: game title "SEW CHAIN" + controls text (CLICK sew / R rethread) + "PRESS SPACE" prompt.
- Game over: "GAME OVER", reason (NEEDLE SNAPPED / TIME UP), final score, best score, "PRESS SPACE" to retry.
- All on-screen TEXT must be ASCII/English only (NO CJK — Pyxel built-in font lacks CJK glyphs).

### Input handling (in update(), these touch pyxel)
- `pyxel.btnp(pyxel.KEY_SPACE)` in TITLE/GAME_OVER → reset + phase=PLAYING.
- `pyxel.btnp(pyxel.MOUSE_BUTTON_LEFT)` in PLAYING → hit-test each alive patch's 24x24 rect (x, y, x+24, y+24); call `_sew(i)`.
- `pyxel.btnp(pyxel.KEY_R)` in PLAYING → `_rethread()`.

### update() flow (PLAYING phase)
1. `self.frame += 1`; `self.elapsed += 1`; `self.timer -= 1`; if timer <= 0 → phase=GAME_OVER ("TIME UP").
2. if super_timer > 0: super_timer -= 1.
3. `_update_heat()`.
4. `_update_needle()`, `_update_patches()`, `_update_floats()`, `_update_particles()`.
5. if shake > 0: shake -= 1.
6. update best_score = max(best_score, score).
