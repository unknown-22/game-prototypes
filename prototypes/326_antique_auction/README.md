# 326 — ANTIQUE AUCTION

## 体験仮説
「価値の絞り込み」と「価格の上昇」を天秤にかけ、ギリギリで掘り出し物を安く競り落として大儲けした瞬間に、ヒヤッとした快感を得られる。

## 実装したコアループ
1. 隠された真の価値 V を持つ骨董ロットが現れる。
2. 評価帯 [lo, hi] が時間とともに V へ向かって狭まる（残余 RESIDUAL=25 は最後まで残る）。
3. オークション価格 P が直線的に上昇し、遅すぎると V を超えて損になる。
4. SPACE/クリックで現在価格で落札。利益 V-P が残高に加算。V が開示される。
5. 入札しないと「SOLD TO RIVAL」（見逃し）。
6. 残高<=0 で BANKRUPT、60 秒で TIME UP。

## うまくいっている点
- 早い入札＝安いが盲目、遅い入札＝情報はあるが高い、という判断が数秒ごとに回る。
- 残余の不確実性により、最後まで「当てる」判断が残る。

## 次に改善するなら最初に触る点
- 評価帯の絞り込みを非線形にし、途中に「急に分かる瞬間」を作る。
- ロットごとの価値分布にレア高額品（ロングテール）を入れて期待感を出す。
