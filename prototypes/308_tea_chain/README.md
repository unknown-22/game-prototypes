# TEA CHAIN (茶道 Tea Ceremony)

茶道をテーマにした色合わせコンボ連鎖アーケード。茶人がお客の注文色に合わせて茶を点て、同色を連続で供して COMBO を伸ばし、虹色の SUPER BREW を目指す。

## Source
- 元アイデア: game_idea_factory #1 (Score 31.8) — 厄災封印デッキ構築「同じカードを連続で使うと効果が変質（強化/暴発）」「UIの連鎖演出（崩壊/増加/圧縮）」
- 再解釈: 「同じものを連続使用 → 同色連続供茶の COMBO」「強化/暴発 → steep 倍率アップ / 点て過ぎ（BITTER）」「連鎖演出 → COMBO チェーン + SUPER BREW」

## Engine
- Pyxel 2.x, 320×240, display_scale=2, 60fps

## 体験仮説
「注文の色を読み、茶が濃くなるのをギリギリまで待って（steep で倍率アップ）、同色を連続で供して虹色の SUPER BREW でコンボが伸びる瞬間に、リスクを取って得をした快感が生まれる」

## 実装したコアループ
1. 客が空席に現れ、注文色（0-3）を吹き出しで表示
2. 茶人の点てる茶色が自動巡回（20f→12f で高速化）
3. steep メーターが毎フレーム +1（上限 45）。溜めるほど供茶時の倍率アップ（1+steep//15 で最大 3 倍）
4. クリック or キー 1/2/3 で客へ供茶
   - 一致: COMBO+1、スコア += 10×combo×倍率（SUPER 中は×3）
   - 不一致: HEAT+15、コンボリセット
   - 点て過ぎ（steep≥45）: HEAT+12、steep リセット（コンボは維持）
5. COMBO≥4 で SUPER BREW（300f 虹色・任意色一致・3倍・HEAT 凍結）
6. 客が待ち切れず帰ると HEAT+5・コンボリセット
7. HEAT≥100 or 60秒タイマーでゲームオーバー

## Controls
- クリック（客席）or キー 1/2/3: その席へ供茶
- ENTER / SPACE: タイトル開始・リスタート

## うまくいっている点
- steep が「今供すか、溜めて倍率を稼ぐか」のリスクとリターンを1つのメーターで表現
- 点て過ぎ（BITTER）がコンボを壊さず HEAT だけ上げるため、溜めすぎの緊張が自然に生まれる
- 客の patience が時間圧を追加し、色巡回との複合判断になる

## 次に改善するなら最初に触る点
- 茶種ごとの個性（例: 特定の茶は steep 上限が低い、マイルドで BITTER にならない等）を足して選択肢を増やす
- 席数を 3→5 に増やし、後半の同時判断の密度を上げる
- SUPER BREW 中の爽快感を強化（画面全体の茶しぶきパーティクルなど）

uv run python prototypes/308_tea_chain/main.py
