# RULE FLUX（ルール・フラックス）

単一ボタンの GO/NO-GO 反射ゲーム。中央に数字（0-9）と色（4色）のトークンが高速で切り替わり、
上部のルールバナー（HIGH / EVEN / WARM / COOL）が現在の通過条件を宣言する。
そのルールがタイマーで次々と「変異」していくのが核心。

## 体験仮説

「ルールが切り替わった直後の1〜2個目で、古いルールの反射をこらえて新しいルールを読み直し、
ギリギリで正しく押せる（あるいは我慢できる）瞬間が面白い」

- メカニクス仮説: ルールを「数字次元」（HIGH=数値5以上 / EVEN=偶数）と「色次元」（WARM=赤黄 /
  COOL=青緑）の間を行き来させることで、プレイヤーに「頭の次元を切り替える」認知負荷を課す。
  この切替が Mechanics（ルール変異タイマー）→ Dynamics（変異直後の反射ミスとの戦い）→
  Aesthetics（読み直して正解できた快感）につながる。
- 検証方法: 1プレイ60秒。指標はスコア、最大コンボ、HEAT（=ミスの蓄積）。ルール変異直後の
  正解率が上達とともに上がるかを観察できる。

## コアループ

1. トークン（数字+色）が中央に表示され、`cycle_interval` ごとに切り替わる。
2. ルールバナーが現在のルールを表示（変異の60フレーム前に「RULE CHANGE!」警告が点滅）。
3. SPACE / クリックで「通過させる」判断を下す：
   - **HIT**（GOトークンで押す）: コンボ+1、スコア = 10×コンボ×（FLUX中は3倍）+ 速度ボーナス
   - **FALSE ALARM**（NO-GOで押す）: HEAT+15、コンボリセット、画面揺れ
   - **MISS**（GOを見逃す）: HEAT+8、コンボリセット
   - **CORRECT RESTRAINT**（NO-GOを我慢）: +5点
4. コンボが4に達すると **FLUX** 発動（300フレーム）：スコア3倍、ルール変異とHEAT減衰が凍結。
   終了時にコンボリセット。
5. HEAT 100（OVERLOAD）または60秒（TIME UP）でゲームオーバー。

## リスクとリターン

- 押すのは危険（FALSE ALARM = HEAT+15）だが HIT はコンボを伸ばして FLUX につながる。
- 我慢は安全（NO-GOでは無傷）だが GO を見逃すと HEAT+8。
- 速度ボーナス（トークン表示前半で押すと+5点）は速い反応を報いる一方、読み間違いのリスクも上げる。

## 操作方法

| 入力 | 動作 |
|---|---|
| SPACE / クリック | 通過判定（押す）／タイトル開始／リトライ |
| RETURN | タイトル開始 |

## エンジン / 仕様

- Pyxel 2.x、320×240、display_scale=2、60fps
- ルール: HIGH（数値5以上）/ EVEN（偶数）/ WARM（赤・黄）/ COOL（青・緑）

## 元になったアイデア

game_idea_factory 出力（2026-08-19、Score 31.45 上位群）のフックを再解釈：
- 「各フロアでルールが1つだけ変わる」→ ルールがタイマーで1つずつ変異
- 「コストは未来の手札を消費」→ 次のルール変化がコスト（先を読む必要）

デッキ構築/オートシューター/ダイスに偏った生成結果のうち、既存コレクションに無い
「GO/NO-GO 認知切替」ジャンルとして採用。コレクション初。

## 次に改善するなら最初に触る点

1. **ルール変異の直後猶予**：変異直後の1〜2トークンは難しすぎる/優しすぎるかの体感調整
   （現状は変異と同時に新しいルールが即適用される）。
2. **FLUX の報酬バランス**：3倍+変異凍結が強すぎる場合は、変異凍結を外して「加速」に変える。
3. **色次元ルールの認知差**：数字ルール（HIGH/EVEN）より色ルール（WARM/COOL）の方が直感的に
   速い可能性。ルールごとの平均正解率を取って難度を均す。
