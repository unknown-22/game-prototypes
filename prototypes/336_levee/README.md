# 336 — LEVEE (Dam / Floodgate Management)

## Source
`game_idea_factory` 出力（2026-08-22, seed 15:00 バッチ）の「発電所（過負荷と放電）」および「配送/物流（流量最適化）」フックを、堤防水門の流量管理ゲームに再解釈したもの。コレクション初のダム/流量管理（resource-flow management）ジャンル。

## Engine

- Python 3.12, 型ヒント, `@dataclass`, `Enum`, 単一ファイル

## Experience Hypothesis (体験仮説)
「満タン寸前まで水を貯めてヘッド圧を高め、決壊寸前のギリギリでゲートを開いて一気に放流し、大量発電するのが気持ちいい。ただし欲張ると決壊する、という怖さと得の天秤を90秒で味わう」

## Core Loop
1. 雨が最上段タンクに流入（時間とともに増加、SURGE時は3倍）
2. 水は開いたゲートを通って下段へ、最下段ゲートから出るとタービンで発電（POWER = スコア）
3. 発電量 = 流量 × (1.0 + 水位/100)。満タンに近いほど高ヘッド圧で倍近く稼げる
4. どのタンクも水位が容量100を超えると LEVEE BREACH（ゲームオーバー）
5. 90秒（5400フレーム）の嵐を生き残れば STORM CLEARED（勝利、残水に応じボーナス）

## Risk / Reward
- 貯める（高ヘッド圧 = 高発電） vs 放流する（安全 = 低発電）
- 約10秒ごとに SURGE が来る（120フレーム前に警告点滅）。事前に排水するか、貯めて耐えるかの判断
- 各タンク水位 > 85 で赤色表示（危険の視覚予兆）

## Controls
- キー 1 / 2 / 3 でゲート0/1/2をトグル
- ゲート矩形をマウスクリックでもトグル
- ENTER（またはクリック）で開始 / リトライ
