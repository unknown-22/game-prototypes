# 313 — HYDRA CHAIN Design Spec

## Concept
A color-match arcade brawler against a many-headed Hydra. The serpent's heads sit in
an arc at the top of the screen, each with a COLOR (one of 4) and a TIER (1-3).
Your blade's color auto-cycles. **CLICK a head to CUT it** when the blade color matches
(score + combo chain; same-color adjacent heads chain-cut together). **SPACE = STRIKE**
the head under the cursor — but this is the inversion: striking does NOT kill a head,
it GROWS it (tier +1). A tier-3 head struck again RAM PAGES (enrage): it resets to tier 1,
spawns an EXTRA head (the hydra multiplies), and costs HEAT. Strike to raise a head's bounty
(higher tier = higher cut score), but never over-feed it.

## "Most Fun Moment" (面白い瞬間)
「頭をギリギリまで突いて育成してから、刃の色を合わせて同色の頭を一気に連鎖切断し、
コンボとスコアが爆発する瞬間」— and the panic when you over-strike and the hydra rampages.

## Core Mechanic
1. Heads (5 initial) each have color (0-3) and tier (1-3). Blade color auto-cycles 20f->12f.
2. Player decision each moment: (a) CUT a head whose color matches the blade (safe, score),
   or (b) STRIKE a head to grow its tier for a bigger eventual cut (risk enrage), or
   (c) wait for the blade to cycle to a desired color.
3. CUT success: remove head, score += 10*combo*tier, combo += 1. Chain: all heads in the
   same contiguous same-color run (in head-list order) are also cut (each scoring + combo++).
4. CUT mismatch (click a head of a different color): HEAT+15, combo reset, head stays.
5. STRIKE: target head tier += 1 (cap 3). Striking a tier-3 head = ENRAGE: HEAT+20, head
   resets to tier 1, and 1 extra tier-1 head spawns (random color).
6. COMBO >= 4 => SUPER BLADE (300f): cut ANY color (no mismatch), 3x score, HEAT frozen.
7. Cut heads respawn (after delay) as tier-1 random-color heads (hydra regrows).
8. HEAT >= 100 => "HYDRA RAMPAGE" game over. 60s timer => "TIME UP" game over.

## Technical Spec
- Screen: 320x240, display_scale=2, Pyxel 2.x, 60fps
- Heads: list[Head], arc layout: x = 36 + i*54 for i in 0..MAX_HEADS-1, y = 70 + 12*((i-2)**2)
- Phase machine: TITLE, PLAYING, GAME_OVER (3 phases)
- Head colors: RED=8, LIME=11, DARK_BLUE=5, YELLOW=10
- Other: BLACK=0, WHITE=7, GRAY=13, GREEN=3, NAVY=1 background
- MAX_HEADS=6, HEADS_START=5, MAX_TIER=3, COMBO_SUPER=4, SUPER_DURATION=300, GAME_LENGTH=3600

## Data Classes
```python
from dataclasses import dataclass
from enum import Enum

class Phase(Enum):
    TITLE = 0
    PLAYING = 1
    GAME_OVER = 2

@dataclass
class Head:
    color: int   # 0..3 (index into COLOR_VALS)
    tier: int    # 1..3

@dataclass
class Particle:
    x: float
    y: float
    vx: float
    vy: float
    life: int
    color: int

@dataclass
class FloatingText:
    x: float
    y: float
    text: str
    life: int
    color: int
```

## Game Class Structure
```python
class Game:
    # __init__: pyxel.init(320,240,...), pyxel.run(update, draw)
    # reset(): init all state below
    # update(): phase dispatch -> _update_title/_update_playing/_update_gameover
    # draw(): phase dispatch -> _draw_title/_draw_playing/_draw_gameover

    # State (ALL pre-init for Game.__new__):
    # phase: Phase
    # score: int
    # combo: int
    # max_combo: int
    # heat: float
    # frame: int          # elapsed playing frames
    # heads: list[Head]
    # blade_color: int    # current blade color index 0..3
    # blade_timer: int
    # super_timer: int    # >0 means SUPER active
    # particles: list[Particle]
    # floats: list[FloatingText]
    # respawn_queue: list[int]  # pending respawn delays
    # shake: int          # screen shake frames remaining
    # _rng: random.Random
```

## Key Methods (Testable — NO pyxel input calls)
- `_cycle_interval() -> int` — max(12, 20 - frame//120)
- `_head_at(x: float, y: float) -> int | None` — index of head under point (or None)
- `_cut_head(i: int) -> None` — cut logic (match check, chain, score, combo, respawn)
- `_chain_run(i: int, color: int) -> list[int]` — contiguous same-color run containing i
- `_strike_head(i: int) -> None` — tier growth / enrage logic
- `_do_cut_score(i: int) -> int` — helper returning score for one head (combo applied)
- `_spawn_head() -> None` — add tier-1 random-color head if under MAX_HEADS
- `_update_heat(delta: float) -> None` — apply delta, clamp, check game over
- `_update_timer() -> None` — decrement frame/timer, check TIME UP
- `_update_blade() -> None` — advance blade_timer, cycle blade_color
- `_update_heads() -> None` — process respawn queue
- `_update_particles() -> None`
- `_update_floats() -> None`
- `_update_super() -> None` — decrement super_timer, freeze heat decay

## Phase Machine
```
TITLE -> (KEY_RETURN/SPACE) -> PLAYING -> (heat>=100 or time up) -> GAME_OVER -> (KEY_RETURN) -> TITLE
```

## Screens
1. TITLE: "HYDRA CHAIN" title, controls text, "PRESS ENTER" blink.
2. PLAYING: heads (arc), blade color indicator, HUD (score/heat bar/timer/combo).
3. GAME_OVER: final score, best score, "GAME OVER" reason, "PRESS ENTER" to retry.

## Rendering Notes
- Head: circle of COLOR_VALS[color], radius grows with tier (8/11/14), tier pips drawn as small
  dots. Enrage flash: brief white ring. Blade indicator at bottom: colored rectangle + "CUT" label.
- SUPER: rainbow border + blade cycles all colors.
- HUD: top-left score, top-right heat bar (vertical), top timer bar, combo under score.
- Head arc: y = 70 + 12*((i-2)**2) so center heads sit higher.

## Animation / Timing Rules
- blade cycle: 20f -> 12f linear over 60s (via _cycle_interval).
- respawn delay: 60f -> 25f linear over 60s.
- SUPER: super_timer = 300 on activation, decrement 1/f; heat frozen while >0.

## Particle System
- Cut success: 8 particles, color=blade, vx in [-2,2], vy in [-3,-1], life 20-35.
- Chain extra: +6 particles per chained head.
- SUPER cut: 20 particles (rainbow colors).
- Mismatch: 4 particles (GRAY), small burst.
- Enrage: 12 particles (ORANGE) + shake=8.

## Input
- Title: KEY_RETURN or SPACE -> start.
- Playing: LEFT CLICK -> cut head at cursor (via _head_at); SPACE -> strike head at cursor;
  also allow KEY_1..4 to set blade color directly for testing convenience.
- Game over: KEY_RETURN -> restart.

## Headless Testing Pattern
- Use `Game.__new__(Game)` to bypass __init__ (avoids pyxel.init/run panic).
- Pre-init ALL instance attributes before calling reset() (see state list above).
- Never call pyxel.btn/btnp/mouse_x/mouse_y in testable methods.
- Define `_make_game()` factory in test file: pre-init, reset(), then g._rng = random.Random(42).
- Note: reset() must initialize self._rng BEFORE any method that consumes it.

## Edge Cases
- No heads under cursor (cut/strike no-op).
- All heads same color (chain cuts everything).
- MAX_HEADS reached (spawn no-op).
- Combo reset on mismatch but not on enrage.
- SUPER expires exactly as timer hits 0.
- Heat decay frozen during SUPER.
