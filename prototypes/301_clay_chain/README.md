# CLAY CHAIN — 陶芸ろくろ × 色合わせCOMBOチェイン

## 体験仮説 (Experience Hypothesis)
「回転する轆轤(ろくろ)の上で、手の色と合う粘土が頂点に来た一瞬を狙って投げ、同じ色を
連続で投げてCOMBOが伸び、SUPER THROWで虹色に変わり全粘土が自動マッチする瞬間が面白い。
色が合わない粘土が迫る時、時間を削って窯で焼いて得点を確保するか、ミスを覚悟して投げるか
迷う駆け引きが面白い」

## 実装したコアループ
1. 轆轤が連続回転（速度 2.0 → 5.0 deg/frame、60秒で加速）
2. 手の色が自動巡回（20f → 12f）
3. SPACE/クリックで頂点(12時位置)の粘土を「投げる」
4. 同色連続 → COMBO連鎖（score = 10 * combo * 倍率）
5. COMBO >= 4 → SUPER THROW（300f 虹色・全色一致・3倍・HEAT凍結）
6. 色違い → 割れて HEAT +15（上限100でゲームオーバー）
7. KILN FIRE (F) = 「未来の手札がコスト」: 4秒(240f)を消費して棚の壺を一括得点化(25点/個)

## 面白い瞬間 / リスクとリターン
- **面白い瞬間**: 同色の粘土が頂点に来た一瞬を狙って連続で投げ、SUPER THROWで虹色に爆発するカタルシス。
- **リスクとリターン**: 色が合わない粘土が迫る時、時間を削って窯焚きで得点を確保するか、ミスを覚悟して投げるか。
  また、窯焚きを待つほど棚の壺が増えて効率は上がるが、時間切れのリスクも増える。

## 操作方法
- SPACE / クリック: 頂点の粘土を投げる
- F: 窯焚き（棚の壺を一括得点化、4秒消費）
- ENTER: タイトルで開始 / ゲームオーバーでリトライ
- ESC: 終了
