# SNIP CHAIN (310)

床屋／理容師をテーマにした色合わせ COMBO 連鎖アーケードゲーム。
コレクション初の「理容／散髪」ジャンル。

## 体験仮説（Experience Hypothesis）

「伸び続ける髪を、巡回するハサミの色に合わせて次々と刈り込み、コンボを重ねて
SUPER SNIP の虹色で一気に刈り上げる瞬間」が気持ちいい。
色違いを切ると「傷(nick)」となり HEAT が上がる緊張感と、髪が伸びて盤面が埋まっていく
プレッシャーが、同色連鎖を追う欲張り行動のリスクになる。

## メカニクス仮説（Mechanics → Dynamics → Aesthetics）

- **Mechanics**: ハサミの色が自動巡回（20f→12f）。同色の髪をクリックで刈ると COMBO
  （score = 10 * combo）。COMBO >= 4 で SUPER SNIP（300f 虹色・任意色一致・3倍・HEAT凍結）。
  色違いは HEAT +15・コンボリセット。髪はセルオートマトン（スナップショット方式）で
  頭皮から上へ生え続ける。
- **Dynamics**: 「同色に固執してコンボを伸ばす」か「髪が伸びるのを放置して色巡回を待つ」
  か、あるいは「色が合わない鎖を我慢して次の巡回を待つ」かの駆け引き。髪が頂上まで
  伸びると OVERGROWN で即ゲームオーバーなので、安全に待てない。
- **Aesthetics**: 連鎖の爽快感（同色コンボ→虹色）と、ミスが熱と盤面の圧迫に複利で効く緊張。

## 実装したコアループ

1. 髪（4色: RED/LIME/DARK_BLUE/YELLOW）が 8×10 グリッド（CELL=24）で頭皮から上へ生える
2. ハサミ色が自動巡回 → クリックで刈る
3. 同色連続 = COMBO 連鎖、COMBO>=4 で SUPER SNIP（虹色・任意色一致・3倍）
4. 色違い = HEAT +15 + コンボリセット（その髪は残る）
5. 失敗条件 3 種: HEAT>=100（NICKED OUT）/ 髪が頂上到達（OVERGROWN）/ 60秒タイマー（TIME UP）

## うまくいっている点

- 髪が「生え続けて盤面を埋める」唯一の成長系 CA で、待つ・切る・欲張るの選択に意味が生まれる
- スナップショット方式の CA 成長（同一パスで連鎖しない）でテスト再現性が高い
- `_snip` / `_grow_hair` / `_update_heat` / `_check_overgrown` を Pyxel 入力から分離し、
  44 のヘッドレステストでロジックを検証

## 次に改善するなら最初に触る点

- 成長速度と HEAT のバランス（GROW_CHANCE=0.35 / grow_interval 60→30）は未プレイ調整。
  手動プレイで「30秒以内に面白い瞬間が起きる」か確認し、髪が伸び切る前にコンボを
  決められる難度に調整する
- スーパー中のスコア爆発感を強化（画面揺れ・パーティクル量）

## 操作方法 / How to run

- タイトル: ENTER か SPACE で開始
- プレイ中: クリックで髪を刈る（ハサミ色と一致でコンボ、不一致は HEAT +15）
- ゲームオーバー: ENTER か SPACE で再挑戦

```bash
uv run python prototypes/310_snip_chain/main.py
```
