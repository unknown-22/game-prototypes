# 328 — TRIAGE: ER Shift

救急外来のトリアージ（患者の重症度判定と処置順の決定）をテーマにした、60秒間シフト制の
意思決定ゲーム。**色合わせ COMBO / HEAT フォーミュラを意図的に破った**「ブレイクアウェイ
シリーズ」の第6弾（323_rule_flux → 324_ticker_surge → 325_fission → 326_antique_auction →
327_photo_finish → 本作）。

## 体験仮説

「症状ピップスだけでは重症度が確定しない中、クラッシュ寸前の重症患者を正しく見抜いて
ギリギリで救うと、賭けに勝った気持ちよさがある」

## 実装したコアループ

見る（ピップス1〜4個と減っていくクラッシュバー）→ 判断する（どの患者を次に処置するか）→
操作する（クリックで処置開始、クラッシュ時計がフリーズ）→ 結果（重症度が判明して得点）→
次の判断へ。1処置スロットしかないため「今この患者に使うか、他を待つか」の順序判断が常に発生する。

## ルール

- 60秒間（3600フレーム）のシフト。待合室は6スロット（2行×3列）。
- 患者は**隠れ重症度**（MINOR=1 / MODERATE=2 / CRITICAL=3）と**見える症状ピップス（1〜4個）**を
  持つ。ピップス = 重症度 ± 1（クランプ1..4）のノイズ信号。4個＝確実に重症、1個＝重症でない、
  2〜3個＝曖昧（このギャンブルが本作の核）。
- 患者をクリックすると処置開始（40フレーム占有）。処置中の患者のクラッシュ時計は**フリーズ**する。
- 処置完了で重症度が判明し得点: MINOR=100 / MODERATE=200 / CRITICAL=300（+声望5回復）。
  クラッシュ時計が90未満で処置した場合「JUST IN TIME +100」。
- 未処置の患者はクラッシュ時計がゼロになるとクラッシュ（死亡）し、声望を失う:
  MINOR=-4 / MODERATE=-12 / CRITICAL=-25。
- 失敗条件: 声望0（MALPRACTICE）または時間切れ（SHIFT OVER）。スコア＝救えた患者の合計。
- 難度上昇（1〜2ノブずつ）: 出現間隔 90→30f、時計スケール 1.0→0.7、重症患者の重み 2→6。

## 操作

- マウス左クリック: 待機中の患者カードをクリックして処置開始
- ENTER: タイトル画面で開始 / ゲームオーバー画面でリトライ

## うまくいっている点

- ノイズ信号が**静的**（待っても情報が増えない）ため、既存の 326/327 の「観察してから決める」
  とは異なる「今すぐ決めないと死ぬ」緊張が生まれている。
- 処置開始でクラッシュ時計がフリーズするため、「危なそうな患者を先にクリックして確保する」という
  戦術選択が自然に発生する。

## 次に改善するなら最初に触る点

- ピップスの情報量をもう1段増やす（例: ピップスに色のヒントを重ねる、あるいは重症度3を5ピップス
  まで広げて「確定重症」の視認性を上げる）。
- 「観察（追加情報を得る代わりに時間を使う）」と「即処置」のトレードオフを1つだけ入れるか検討する。
