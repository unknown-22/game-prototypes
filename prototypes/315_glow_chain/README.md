# 315_glow_chain — GLOW CHAIN (ガラス吹き / Glassblowing)

色合わせアーケードのコレクション初となる**ガラス吹き（Glassblowing）**プロトタイプ。
溶けたガラス（ザ・ギャザー）の色＝温度を炉の炎で操り、注文の色と一致した瞬間に吹いて
器を完成させる。

## 体験仮説

「炎で温度を操り、注文の色と一致した瞬間に吹いて器を完成させる。勢いよく再加熱して
素早く仕上げるか、慎重に冷まして安全に進めるかの駆け引きで、コンボが一気に伸びる
気持ちよさと、オーバーヒートでガラスが溶け落ちるヒヤリを味わう。」

## 実装したコアループ

1. 現在の注文色（目標の温度帯）を読む
2. Rキーを押して再加熱（離すと自然冷却）。ガラスの色が COLD(青)→COOL(緑)→WARM(黄)→HOT(赤) と変化
3. ガラス色が注文色と一致したら SPACE で吹く → 成功：COMBO + スコア、ガラスがリセットされ次の注文へ
4. 色違い・オーバーヒート・凍結はすべて HEAT ペナルティ + コンボリセット
5. COMBO ≥ 4 で SUPER BLOW（300f 虹色・任意色一致・スコア3倍・HEAT凍結・冷却停止）
6. HEAT ≥ 100（MELTDOWN）または 60秒（TIME UP）でゲームオーバー

## メカニクス仮説（MDA）

- **Mechanics**: 温度は自動で下がる（冷却）。Rキー再加熱で上昇。SPACE で吹く（温度帯が注文色と一致した時のみ成功）。
- **Dynamics**: 勢いよく再加熱すれば注文を早く仕上げてコンボを伸ばせるが、100 に達すると SAG（溶け落ち）。放っておくと 0 まで冷えて CRACK（割れ）。「押す vs 待つ」を常に選ぶ。
- **Aesthetics**: 色がピタッと合って吹いた瞬間に器が弾け、コンボが爆発する快感。

## 操作

| 入力 | 動作 |
|------|------|
| R（長押し） | 再加熱（炉の炎で温度上昇） |
| SPACE | 吹く（現在の注文に挑戦） |
| SPACE / RETURN / クリック | タイトル開始・リスタート |

## リスクとリターン

- **オーバーヒート（SAG）**: 再加熱中に温度が 100 に達すると溶け落ち。HEAT+20・コンボリセット。
- **凍結（CRACK）**: 温度が 0 まで冷えると割れる。HEAT+15・コンボリセット。
- **色違い（WRONG!）**: 注文と違う色で吹くと失敗。HEAT+15・コンボリセット。
- **SUPER BLOW**: コンボ4以上で発動。任意色一致・3倍スコア・HEAT凍結（リスク消滅のご褒美）。

## うまくいっている点

- 「温度を操る」操作が既存のオート巡回色合わせ（色を待つだけ）と明確に異なり、能動的な駆け引きが生まれている。
- HEAT リスクが炉の炎と文字通り対応し、テーマとメカニクスが一致している。
- コンボ→SUPER BLOW の流れが既存テンプレートと整合し、再挑戦のテンポが速い。

## 次に改善するなら最初に触る点

- 注文ごとの制限時間（顧客の忍耐）を追加して、温度調整以外の時間圧を入れる。
- 温度帯を4色→5色にして COLD と COOL の差を細かくし、判定の緊張感を上げる。
- 高難度注文（HOT専用・ボーナス倍率）でリスク/リターンの勾配を強める。
