# KNIGHT CHAIN (280)

チェス盤上のナイトL字移動 × 色合わせCOMBOチェインのチェスパズル。
（初のチェスパズルジャンル）

## 体験仮説
「同色ターゲットをナイトのL字ジャンプで次々に踏み抜き、COMBOを積み上げてSUPER KNIGHTを発動させる——チェスの移動制約が色選択の緊張感を高め、限られた移動先から最善を選ぶ判断が面白い」

## 操作
- マウスクリック：ハイライトされたL字移動先（最大8箇所）のいずれかをクリックして移動
- SUPER MODE中：ボード上の任意のマスにワープ可能
- R / SPACE：タイトル画面で開始、ゲームオーバー画面でリトライ

## ルール
- ナイトの色が自動巡回（90f → 40f、時間で加速）
- 同色ターゲットに着地 → COMBO+1、スコア加算
- 異色ターゲットに着地 → COMBOリセット、HEAT+15
- COMBO ≥ 4 → SUPER KNIGHT（300f 虹色、全色マッチ、3倍スコア、ワープ移動）
- HEAT ≥ 100 または 60秒経過 → ゲームオーバー

## コアループ
1. ナイトのL字移動可能先（ハイライト）を確認
2. ターゲットの色とナイトの色を比較
3. 同色を選んでCOMBO連鎖 → SUPER KNIGHTへ
4. 異色を避けつつ高スコアを狙う
5. リスタートで再挑戦

## うまくいっている点
- ナイトのL字移動（8方向の制約）が「選ぶ」判断を自然に生む
- SUPER KNIGHTで任意ワープ可能になる解放感
- ターゲットの色がハイライト枠線で視認しやすい
