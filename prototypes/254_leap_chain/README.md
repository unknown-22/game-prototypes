# LEAP CHAIN (254_leap_chain)

走り幅跳び × 色合わせ COMBO チェイン プロトタイプ。

## 体験仮説

「助走パワーを溜めて跳躍し、同色の着地ゾーンに連続で決めて COMBO を積み上げ、SUPER LEAP で一気に大量得点するカタルシスが面白い」

## 実装したコアループ

1. SPACE 長押しで助走パワー充填（0→100）
2. マウス Y 位置で跳躍角度を調整
3. SPACE を離して跳躍（放物線飛行）
4. 着地ゾーンの色とプレイヤー色の一致で COMBO 成立
5. COMBO>=4 で SUPER LEAP（300f 虹色モード、全色一致、3倍スコア）
6. 6回の跳躍、60秒タイマー、HEAT リスク

## 操作

| 操作 | 内容 |
|------|------|
| SPACE 長押し | 助走パワー充填 |
| SPACE 離す | 跳躍 |
| マウス Y 位置 | 跳躍角度（上=高角度、下=低角度） |

## うまくいっている点

- 跳躍→着地→COMBO 判定の短いプレイループ（数秒）
- SUPER LEAP 発動時の虹色エフェクトと大量得点が気持ちいい
- HEAT リスクが「色を合わせるか安全に飛ぶか」の判断を生む
- 6回制限が「あと1回で SUPER LEAP を決めたい」という緊張感を生む

## 次に改善するなら

- 風システムを追加して跳躍にランダム性を持たせる
- ゴーストトレイルでベストジャンプを表示
- 助走リズムタップ（一定間隔で SPACE をタップ）でボーナスパワー
- 三段跳び（Triple Jump）モードの追加
