# SKY SURGE — Skydiving Color-Match COMBO Chain

## 体験仮説
「落下中に同色リングを連続通過してCOMBOを積み重ね、SUPER DIVEで虹色爆発する怖さと爽快感を味わってほしい。より長くフリーフォールを続けるか、安全に早くパラシュートを開くかのリスクとリターンが面白い。」

## 実装したコアループ
1. プレイヤーが自動落下、左右移動で色付きリングを通過
2. 同色連続通過でCOMBO構築（1→2→3→4...）
3. COMBO >= 4でSUPER DIVE発動（300fレインボーモード、全色マッチ、3倍スコア）
4. 色を間違えるとCOMBOリセット＋HEAT+15、HEAT >= 100でゲームオーバー
5. 15秒ダイブ→パラシュート開く（SPACEで早期開傘、早いほどボーナス高）
6. 60秒タイマー、4-5回のダイブを繰り返す

## うまくいっている点
- スカイダイビングという新鮮なジャンル（コレクション初）
- FALLING→CHUTE→LANDED→新ダイブのサイクルがテンポ良い
- HEATリスクとパラシュート早期開傘のトレードオフが機能している
- 難度上昇（落下速度、リング間隔、色巡回速度）が自然に緊迫感を高める

## 次に改善するなら最初に触る点
- 風の要素（横方向のドリフト）を追加して左右移動の駆け引きを深める
- ダイブごとに異なるリング配置パターン
- フォーメーション飛行ボーナス（複数リングを特定順序で通過）
- ベストスコアのローカル保存
