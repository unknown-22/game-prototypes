# ORIGAMI CHAIN (307)

折り紙を折って同色を重ね、融合（合成）でCOMBOを伸ばすパズルアクション。
コレクション初の「折り紙 / 紙折り」ジャンル。

## 体験仮説

「紙の色模様を読んで融合が最大になる折り軸を選び、重なり合う同色が連鎖的に融合して
スコアが爆発する瞬間が気持ちいい。逆に色を間違えると永続的な折り目（デッドセル）が
残って追い込まれる緊張感が、折る軸の選択に意味を持たせる。」

## 実装したコアループ

1. 8x8 の正方形の折り紙（各マス = 色付きセル、4色）を見る
2. 折る軸を選ぶ：**CLICK = 縦折り**（右半分を左へ）、**SPACE = 横折り**（下半分を上へ）
3. 折りで重なったペアを解決：
   - 同色 → 融合（FUSION）: `score += 10 * combo * mult`、combo+1
   - 色違い → 折り目（死んだセル = -1）+ HEAT+10、comboリセット
   - 死セル同士/死セル+生セル → 中立（変化なし）
4. 紙は折るたびに半分になる（8x8 → … → 1x1）
5. 1x1 に到達 → 折り鶴完成（+500 生 / +100 死）→ 新しい 8x8 の紙が出現
6. COMBO >= 4 で SUPER FOLD（虹色・任意色融合・スコア3倍・HEAT凍結、300f）
7. HEAT >= 100 または 60 秒（3600f）でゲームオーバー

## リスクとリターン

- **軸選択の駆け引き**：同色融合が最大になる軸（縦/横）を読んで選ぶ。間違えると折り目が
  残り、紙の融合ポテンシャルが永続的に下がる（複利で効く）。
- **鶴完成 vs 温存**：色違いでも早く紙を小さくして鶴完成ボーナスを狙うか、無理せず
  温存するか。紙が小さくなるほど折れる軸が限られ、終盤は選択肢が絞られる。

## 難度上昇

- 時間経過で新シートの色数が 3 → 4 → 5 色に増える（融合が難しくなる）。
  - 20秒経過: 4色 / 40秒経過: 5色

## 操作方法

| 操作 | 効果 |
|------|------|
| 左クリック（紙の上） | 縦折り（右半分を左へ） |
| SPACE / ENTER | 横折り（下半分を上へ） |
| SPACE / ENTER | タイトル開始 / リスタート |

## うまくいっている点

- 折り紙の「折って重ねる = 合成圧縮」が機械的に忠実に再現できている。
- 折り目（死セル）が「log/replay が資産」＝ミスの痕跡の永続化として機能している。
- 折るたびに紙が半分になるため、1枚あたり約6折りで鶴が完成し、短いループが何度も回る。

## 次に改善するなら最初に触る点

- 縦折り・横折りの方向（右→左 / 下→上）が固定だが、スコア的には対称なので差がない。
  方向選択に意味を持たせるなら「どちらの面を上に残すか」で色を選べるようにする余地がある。
- 折り軸の予測結果を折る前にプレビュー表示すると「読んで選ぶ」楽しさがより明確になる。
