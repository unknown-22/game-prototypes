# LEAP CHAIN — Long Jump Color-Match COMBO Chain Prototype

## Concept
Side-view long jump (走り幅跳び) with color-matching COMBO chain mechanics.
Reinterpreted from dice/bag roguelite idea #1 (Score 32.35):
- "synthesis compression" → same-color consecutive landings = COMBO chain → SUPER LEAP
- "CA grid fills up" → HEAT risk system

## Core Mechanic
Player holds SPACE to build run power, releases to jump. Runner color auto-cycles (RED/LIME/DARK_BLUE/YELLOW).
Same-color consecutive landing zone hits = COMBO chain (score=distance*combo*multiplier).
COMBO>=4 triggers SUPER LEAP (300f rainbow mode, any-color match, 3x score, always max power, HEAT gain disabled).

## "Most Fun Moment"
Building a COMBO chain through perfect-color landings, then hitting SUPER LEAP for a massive rainbow jump that clears all zones at 3x score.

## Risk/Reward
- Same-color landings build COMBO for high scores and SUPER LEAP
- Wrong-color landing resets COMBO + HEAT+15
- Foul (land before first zone / overstep) = HEAT+20
- HEAT>=100 → game over
- 6 jumps, 60s timer

## Phase Machine
- TITLE: title screen, show controls, press SPACE to start
- APPROACH: runner auto-runs rightward, SPACE held=charge power, SPACE released=launch
- FLIGHT: parabolic arc (gravity, vx, vy from power+angle)
- SCORING: check landing zone, compute score/combo/HEAT, show particles+floating text
- GAME_OVER: if HEAT>=100 or timer=0, show score, press SPACE to restart
- VICTORY: after 6 jumps, show best distance + total score

## Data Classes

```python
from dataclasses import dataclass, field
from enum import Enum, auto

class Phase(Enum):
    TITLE = auto()
    APPROACH = auto()   # holding SPACE, building power
    FLIGHT = auto()     # in the air, parabolic
    SCORING = auto()    # landing + score resolution
    GAME_OVER = auto()
    VICTORY = auto()

@dataclass
class Particle:
    x: float
    y: float
    vx: float
    vy: float
    life: int
    color: int

@dataclass
class FloatingText:
    x: float
    y: float
    text: str
    life: int
    color: int

@dataclass
class Zone:
    x: float          # center x
    y: float          # ground y
    width: int        # zone width
```


## Input
- SPACE: hold to charge power in APPROACH, release to jump
- Mouse Y at release: affects jump angle (higher Y on screen = steeper angle, more height/shorter distance)
- No other keys needed

## Rendering
- TITLE: "LEAP CHAIN" title, "Long Jump Color-Match", "HOLD SPACE to charge", "RELEASE to jump", "Mouse Y = angle", "Press SPACE to start"
- APPROACH: runner stick figure moving right, power bar (LIME→YELLOW→RED), foul line (WHITE vertical line), runway (BROWN ground), current color indicator
- FLIGHT: runner in arc (stick figure rotated), trail particles, landing zones visible below
- SCORING: particles burst on landing (match=many, super=rainbow, mismatch=few), floating text (+score/COMBO xN/WRONG!/FOUL!/SUPER LEAP!), screen shake on SUPER
- GAME_OVER: "GAME OVER", final score, best distance, "Press SPACE to retry"
- VICTORY: "VICTORY!", best distance, total score, all 6 jump distances listed
- HUD during play: score, combo, jump #/6, timer, HEAT bar, color name, SUPER timer
- Rainbow border + runner glow during SUPER
- Zones: colored rectangles on ground with distance labels

## Particle System
- On match: 8-15 particles of landing zone color, velocity spread in arc
- On SUPER: 20-30 rainbow particles (cycling colors)
- On mismatch/foul: 4-6 gray particles
- Particle gravity=0.1, life=15-30

## Edge Cases
- Release SPACE after foul line: auto-foul, no jump distance
- All 6 jumps used: VICTORY phase
- Timer reaches 0 mid-jump: finish current jump, then GAME_OVER
- HEAT reaches 100 during scoring: GAME_OVER after current jump scores
- SUPER mode: if active when jump starts, always max power, any-color match

## Headless Testing Pattern
Use `Game.__new__(Game)` to bypass `__init__`. Pre-init all attributes, then call `g.reset()`.
Test all pure-logic methods. Never call methods that access `pyxel.btn`, `pyxel.btnp`, `pyxel.mouse_x`, `pyxel.mouse_y`, or `pyxel.play()` in tests.
