# 291 Ink Chain — Calligraphy Brush COMBO

書道（カリグラフィー）をテーマにしたブラシストロークCOMBOチェインパズル。

## 体験仮説

同じ色の筆運びでコンボを繋ぎ、SUPER BRUSHでキャンバス全体が虹色に輝き、インクが連鎖的に広がる瞬間が面白い。

## コアループ

1. インク色が自動循環（RED→LIME→DARK_BLUE→YELLOW→...）、25f→12fで加速
2. マウスクリックでグリッドセルに現在のインク色を塗る
3. 同色連続ストローク = COMBOチェイン（score = 10 × combo × multiplier）
4. COMBO>=4 で SUPER BRUSH（300f レインボーモード、全色一致、3xスコア）
5. CAインク滲み：15f毎に塗られたセルの20%が隣接空セルに伝播
6. HEATリスク：間違った色 = +15 HEAT、decay -0.02/f、cap 100 = ゲームオーバー
7. 60秒タイマー（1800f @ 30fps）

## 操作方法

| 操作 | 動作 |
|------|------|
| マウス移動 | ブラシカーソル移動 |
| 左クリック | セルにインクを塗る |
| キー 1-4 | インク色を手動選択 |
| SPACE | タイトルから開始 |
| R | ゲームオーバーからリトライ |

## 技術仕様

- Pyxel 2.x, 320×240 @ 30fps
- 10×8 グリッド（24px セル）
- 4色インク: RED(8), LIME(11), DARK_BLUE(5), YELLOW(10)
- Phase: TITLE / PLAYING / GAME_OVER
- 454 lines main.py, 25 headless tests

## うまくいっている点

- CAインク滲みが「log/replay as asset」フックを自然に表現
- SUPER BRUSHの虹色エフェクトと3xスコアが気持ちいい瞬間を提供
- グリッド全体の塗り状態が永続的な「筆跡ログ」として機能

## 次に改善するなら
