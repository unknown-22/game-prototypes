# 328 — TRIAGE: ER Shift Design Spec

## Concept
You are an emergency-room triage nurse working a 60-second shift. Patients keep arriving in a
6-slot waiting room. Each patient has a HIDDEN true severity (minor / moderate / critical) and a
VISIBLE noisy "symptom pips" readout (1-4 pips) that CORRELATES with — but does not reveal — that
severity. You have ONE treatment slot: click a patient to start treating them; treatment occupies
you for a fixed duration, then reveals their true severity and awards score. Every untreated
patient's "crash timer" (time until they crash/walk out) ticks down; when it hits zero they crash
and cost you reputation (a critical crash is catastrophic). Read the noisy signal, gamble on the
ambiguous patients, and save the criticals before they crash.

## "Most Fun Moment" (面白い瞬間)
症状ピップスだけでは判断できない患者の中から、クラッシュ寸前の重症患者を見抜いて「ギリギリで救う」
瞬間が気持ちいい。

## Core Mechanic
1. Loop: observe the waiting room → read each patient's symptom pips (1-4) and their draining crash
   bar → click a patient to start treatment (this FREEZES their crash timer so they can't die on the
   table) → treatment completes, severity is revealed, score/rep awarded → new patients keep
   arriving, other timers keep ticking → next decision.
2. Input → response → feedback: mouse click on a WAITING patient → nurse starts treating
   (card highlights LIGHT_BLUE, timer freezes) → after TREAT_TIME frames the card flashes its
   revealed severity color (minor=LIME / moderate=YELLOW / critical=RED), a floating score popup and
   particle burst fire, then the slot clears.
3. Risk/reward:
   - Treating a critical = 300 pts + reputation recovery; treating a minor = only 100 pts (you
     "wasted" your only slot on a low-value patient).
   - Letting a critical crash = -25 rep (devastating); a minor crash = -4 rep (trivial).
   - Pips signal: 4 pips = definitely critical; 1 pip = never critical; 2-3 pips = ambiguous
     (the interesting gamble). The decision is ORDERING under a death clock, not waiting to learn
     more (pips are fixed at spawn — waiting is dangerous, not informative).

## Technical Spec
- Screen: 320×240, display_scale=2, Pyxel 2.x, 60fps, GAME_DURATION=3600 frames (60s).
- Waiting room: 6 slots in a 2-row × 3-column grid.
  - Card size 88×64 px. Column x = [16, 116, 216]; row y = [64, 140]. (Card spans x..x+88, y..y+64.)
  - Slot index 0..5: idx -> col = idx % 3, row = idx // 3.
- Phase machine: TITLE, PLAYING, GAME_OVER.
- Colors:
  - Background: DARK_BLUE (5). Card fill: GRAY (13). Card border: WHITE (7).
  - Pips: YELLOW (10). Crash warning "!": RED (8) pulsing when crash_timer < CRASH_WARN (150f).
  - Reveal colors: minor LIME (11), moderate YELLOW (10), critical RED (8).
  - Treating highlight: LIGHT_BLUE (6). Nurse cursor: WHITE (7) cross.
  - Reputation bar: LIME (11) > YELLOW (10) > ORANGE (9) > RED (8) as it drains.
  - Timer bar: CYAN (12). HUD text: WHITE (7).

## Data Classes
```python
class Severity(Enum):
    MINOR = 1
    MODERATE = 2
    CRITICAL = 3

class PatientState(Enum):
    WAITING = 0
    TREATING = 1
    TREATED = 2   # brief reveal flash then slot clears
    CRASHED = 3   # brief crash flash then slot clears

@dataclass
class Patient:
    severity: Severity        # hidden true severity
    pips: int                 # 1..4 noisy visible signal
    crash_timer: int          # frames until crash if untreated
    state: PatientState = PatientState.WAITING
    flash: int = 0            # remaining reveal/crash flash frames

@dataclass
class Particle:
    x: float
    y: float
    vx: float
    vy: float
    life: int
    color: int
```

## Game Class Structure
```python
class Game:
    # __init__: pyxel.init(320, 240, title=..., display_scale=2); pyxel.run(self.update, self.draw)
    # reset(): init all state below
    # update(): phase machine dispatch
    # draw(): phase machine dispatch

    # Key state (ALL assigned in reset()):
    # phase: Phase
    # slots: list[Patient | None]       # length 6
    # treating_slot: int | None         # index of patient being treated (None = idle)
    # treat_timer: int                  # frames remaining in current treatment
    # score: int
    # rep: int                          # reputation 0..100, game over at 0
    # frame: int                        # elapsed frames of PLAYING
    # spawn_timer: int                  # countdown to next spawn
    # best_score: int                   # persisted across runs
    # rng: random.Random                # seeded; tests overwrite with Random(42)
    # particles: list[Particle]
    # floats: list[FloatingText]        # (x, y, text, life, color) — use a small dataclass
    # shake: int                        # screen-shake frames remaining
    # saved_count: int                  # total patients treated
    # crashed_count: int                # total patients crashed
    # game_over_reason: str             # "MALPRACTICE" or "SHIFT OVER"
```

## Key Methods (Testable — NO pyxel input calls)
- `_make_patient(severity: Severity, rng: random.Random) -> Patient` — pure factory. pips =
  clamp(int(severity) + rng.choice([-1, 0, 1]), 1, 4). crash_timer per severity:
  MINOR = rng.randint(900, 1500), MODERATE = rng.randint(500, 800),
  CRITICAL = rng.randint(240, 420); all multiplied by `_timer_scale()` (see below).
- `_timer_scale() -> float` — 1.0 -> 0.7 linear over 60s: `1.0 - 0.3 * (frame / 3600)`.
- `_spawn_interval() -> int` — max(30, 90 - frame // 60).
- `_severity_weights() -> tuple[float, float, float]` — weights (minor, moderate, critical).
  critical weight = 2 + frame // 900 (2 -> 6); minor weight = 5 - frame // 1200 (5 -> 2);
  moderate weight = 3 (constant). Use rng.choices([MINOR, MODERATE, CRITICAL], weights).
- `_spawn_patient() -> None` — if any empty slot: pick a random empty slot, severity via
  _severity_weights, assign _make_patient(severity, rng). Does nothing if all 6 slots full.
- `_start_treatment(idx: int) -> bool` — only if slot idx is a WAITING patient AND treating_slot is
  None. Sets patient.state = TREATING, treating_slot = idx, treat_timer = TREAT_TIME. The patient's
  crash_timer is FROZEN while TREATING. Returns True on success.
- `_update_treatment() -> None` — if treating_slot is not None: decrement treat_timer; when it hits
  0, call `_resolve_treatment()`.
- `_resolve_treatment() -> None` — p = slots[treating_slot]; p.state = TREATED; p.flash = REVEAL_FRAMES;
  gain = p.severity.value * 100; if p.severity == CRITICAL: self.rep = min(100, self.rep + 5);
  if p.crash_timer < JUST_IN_TIME (90): gain += 100 (JUST IN TIME bonus); self.score += gain;
  self.saved_count += 1; spawn particles + floating text (draw-side); treating_slot = None.
  (Slot stays occupied with state=TREATED until flash expires — a separate cleanup step clears it.)
- `_update_patients() -> None` — for each slot with a WAITING patient: decrement crash_timer; if
  crash_timer <= 0: crash -> patient.state = CRASHED, flash = CRASH_FRAMES, rep penalty by severity
  (MINOR -4 / MODERATE -12 / CRITICAL -25), crashed_count += 1, shake. (TREATING patients' timers
  do NOT decrement — frozen.)
- `_cleanup_flashes() -> None` — for TREATED/CRASHED patients with flash > 0, decrement flash; when
  flash hits 0, set slot = None (clears the slot).
- `_tick() -> None` — advance ONE frame of PLAYING (the inner logic, no pyxel input): frame += 1;
  decrement spawn_timer (spawn when <= 0 and reset to _spawn_interval()); _update_treatment();
  _update_patients(); _cleanup_flashes(); _check_game_over().
- `_check_game_over() -> None` — if rep <= 0: rep = 0, phase = GAME_OVER, reason = "MALPRACTICE";
  elif frame >= GAME_DURATION: phase = GAME_OVER, reason = "SHIFT OVER"; update best_score.
  Threshold check BEFORE any decay-style mutation (none here, but keep pattern).

## Phase Machine
```
[TITLE] → (KEY_RETURN or click) → [PLAYING] → (rep<=0 or frame>=3600) → [GAME_OVER] → (KEY_RETURN) → [PLAYING/reset]
```

## Screens
1. TITLE: game title "TRIAGE: ER SHIFT", subtitle "Save the criticals. Read the signs.",
   controls: "CLICK a patient to treat" / "ENTER to start". Advance on KEY_RETURN.
2. GAME: 6 patient cards (pips + crash bar + "!" warning), HUD (SCORE top-left, REP bar top-center,
   TIMER bar top, SAVED/CRASHED counts). Nurse treating highlight on active card.
3. GAME_OVER: reason ("SHIFT OVER" / "MALPRACTICE"), final SCORE, BEST, patients saved/crashed,
   "ENTER to retry".

## Rendering Notes
- Card: rect(16..104, 64..128) etc. filled GRAY with WHITE border; crash bar drawn as a thin bar
  along the card bottom, colored LIME->YELLOW->ORANGE->RED by remaining fraction; pips as YELLOW
  squares (4px) along the top; "!" drawn in RED pulsing (alternate on frame//15 % 2) when
  crash_timer < CRASH_WARN.
- TREATING card: LIGHT_BLUE border + a shrinking progress bar. TREATED flash: full-card fill in the
  reveal color fading via flash countdown. CRASHED flash: RED fill + "CRASH"/"CODE BLUE" text.
- Rep bar: 100px wide, top center; color bands LIME(>60)/YELLOW(>30)/ORANGE(>15)/RED(else).
- Floating score text ("+300", "JUST IN TIME +100", "CRASH!") rising and fading.
- Screen shake (offset via pyxel.camera) on critical crash (10 frames).

## Animation / Timing Rules
- TREAT_TIME = 40 frames. REVEAL_FRAMES = 25. CRASH_FRAMES = 30. JUST_IN_TIME = 90. CRASH_WARN = 150.
- Spawn: initial spawn_timer = _spawn_interval(); on spawn reset to _spawn_interval().
- Escalation (1-2 knobs at a time): spawn_interval 90->30f, timer_scale 1.0->0.7, severity weights
  shift toward critical (critical 2->6, minor 5->2, moderate fixed 3).

## Particle System
- Spawn on treatment resolve: count = 6 + severity*4 (minor 10, moderate 14, critical 18).
- Spawn on crash: 8 particles (RED for critical, ORANGE for moderate, GRAY for minor).
- Velocity: random angle, speed 0.5..2.0. Life: 15..35. Gravity: none. Color: reveal color
  (LIME/YELLOW/RED) for resolve, crash color for crash. Floating text also spawned alongside.

## Input
- MOUSE_BUTTON_LEFT click: in TITLE -> start game; in PLAYING -> find slot under cursor
  (col = (mouse_x - 16) // 100 if within card bounds, row = (mouse_y - 64) // 76); if that slot has
  a WAITING patient, call `_start_treatment(idx)`. In GAME_OVER -> restart.
- KEY_RETURN: TITLE -> start; GAME_OVER -> restart.

## Headless Testing Pattern
- Use `Game.__new__(Game)` to bypass __init__ (avoids pyxel.init/run panic).
- Pre-init ALL instance attributes before calling reset().
- Never call pyxel.btn/btnp/mouse_x/mouse_y in testable methods.
- Separate logic from input: core methods take explicit params, wrappers call pyxel.
- Define `_make_game()` factory in test file for consistent setup; seed rng = random.Random(42).
- reset() should use `getattr(self, name, default)` for rng/best_score so the factory is simple.

## Edge Cases
- All 6 slots full -> _spawn_patient() is a no-op (no crash, no override).
- Clicking an empty/treated/crashed slot -> _start_treatment returns False, no-op.
- Starting treatment while already treating -> returns False (single slot enforced).
- TREATING patient's crash_timer must NOT decrement during treatment.
- rep clamp: min(100, rep + 5) on critical save; rep floored at 0 on game over.
- crash_timer reaching exactly 0 (==0) triggers crash (use <= 0).
- pips clamp bounds: severity 1 + (-1) = 0 -> clamp to 1; severity 3 + 1 = 4 -> clamp to 4.
