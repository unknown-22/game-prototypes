# WEATHER CHAIN (305_weather_chain)

色を当てる天気予報。気象予報士になり、画面右から流れてくる色付きの気象前線（雲）の色を
「予報」する。同色連続的中で COMBO が伸び、COMBO>=4 で SUPER FORECAST（虹色・任意色
マッチ・スコア3倍）が発動する。

## 体験仮説

「予報色がちょうど合うタイミングで SPACE を押して、次々と的中させてコンボを重ね、SUPER
FORECAST の虹色で一気にスコアが爆発する瞬間」を気持ちよく感じてほしい。

## 実装したコアループ

- 4種の天気（SUN=黄 / RAIN=青 / SNOW=白 / THUNDER=紫）。予報色は自動巡回（20f→12f）。
- 気象前線が右端（x=320）から左へ漂流（速度 1.0→2.5）。
- 予報線 x=56 に到達した前線に対し SPACE で予報を発令（armed 判定 = 最小 x の前線）。
  - 予報色 == 前線色 → 的中: COMBO++, score += 10*combo*倍率。
  - 不一致 → WRONG: HEAT+15, COMBO リセット。
  - 前線が画面左から消える（x<-20）→ MISS: HEAT+5, COMBO リセット。
- 天気特有の捻り: 前線は一定間隔で「!」を点滅させた後、30% の確率で別の色に変化する
  （天気の不確実性＝部分観測）。予報が届くまでに色が変わるかも、という駆け引き。
- COMBO>=4 → SUPER FORECAST（300f: 虹色ボーダー、任意色マッチ、3x、HEAT凍結）。
- HEAT: 不一致+15 / 見逃し+5 / 減衰-0.02/f / 上限100でゲームオーバー。60秒タイマー
  （3600f）。難度上昇: 出現間隔 90f→30f、前線速度 1.0→2.5、色巡回 20f→12f。

## うまくいっている点

- 巡回する予報色 × 左へ流れる前線 × いつ変わるか分からない色変化、の3つの時間的圧力が
  噛み合い、「待つか・今押すか」の判断が短い間隔で発生する。
- 的中時に COMBO が伸び、SUPER FORECAST 発動で画面が虹色に包まれる即時フィードバック。

## 次に改善するなら最初に触る点

- 前線の色変化（shift）がランダムすぎて運要素が強い。プレイヤーが「変化しそうな前線」を
  見分けられる予兆（点滅パターンの違いなど）を追加する。
- armed 判定が「最小 x」のみなので、複数前線が同時に到達した時の選択余地が薄い。複数
  前線を同時に予報できる（コンボをまとめて取れる）リスク/リターンを検討。

## 操作方法

- タイトル: SPACE / RETURN で開始
- プレイ中: SPACE で予報を発令（armed 前線に対して）
- ゲームオーバー: R で再挑戦

## 実行

```bash
uv run python prototypes/305_weather_chain/main.py
```
