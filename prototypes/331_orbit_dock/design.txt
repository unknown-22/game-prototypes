## Core premise (the one fun moment)
ギリギリまで航路を詰めて、衝突しそうな宇宙船をすれすれで避けながら次々とドッキングさせるのが面白い。
(Threading ships tightly past each other and docking them one after another is the fun.)

## Experience hypothesis
Rush to dock as many spacecraft as possible under a 60-second clock, while every
ship you are NOT currently steering keeps drifting — so ignoring a ship is dangerous.

## Mechanics hypothesis (MDA)
- Mechanics: ships drift on a fixed heading/speed; the player steers ONE selected ship
  at a time (rotate heading left/right, throttle up/down); ships dock by reaching a bay
  slowly; collisions and fuel-out lose ships.
- Dynamics: juggling multiple drifting ships creates near-miss deconfliction tension and a
  "who do I save first" priority decision under the clock.
- Aesthetics: white-knuckle near-misses + the relief of a successful dock.

## Data model (dataclasses, type-hinted)

## Game class `Game`

## Game constants (class-level)
- `SCREEN_W=320, SCREEN_H=240`
- `BAYS`: 3 docking bays at fixed positions, e.g. `[(40,60),(160,40),(280,60)]` radius 16
  (top edge is the "station").
- `SHIP_RADIUS=4`, `COLLIDE_DIST=8` (two ships within this center distance collide).
- `DOCK_RADIUS=16`, `DOCK_SPEED_MAX=0.9` (ship must be slower than this to dock).
- `FUEL_START=1800` (30s of fuel), `FUEL_LOW=300`, `FUEL_CRIT=120`.
- `LIVES_START=3`, `GAME_DURATION=3600` (60s).
- `TURN_RATE=3.0` (deg/frame while key held), `THROTTLE_ACCEL=0.03`, `SPEED_MIN=0.0`,
  `SPEED_MAX=2.5`.
- Spawn escalation: `spawn_interval(frame)` module-level pure fn returning
  `max(50, 200 - frame // 24)` (starts 200f, ramps to 50f). Also `spawn_speed(frame)`
  returning `min(2.2, 0.8 + frame / 1800)` (entry speed ramps up).

## Phases
`class Phase(Enum):` with members `TITLE, PLAYING, GAME_OVER`. Real-time game, so the
phase machine is simple. (Do NOT use a turn-based DRAW/PLAYER_TURN/ENEMY_TURN machine.)

## Gameplay rules (implement as pure, testable methods — no pyxel input inside them)
- `_spawn_ship()`: create a Ship entering from a random screen edge (x=0, x=320, y=0,
  or y=240) with heading pointing roughly toward screen center, `speed=spawn_speed(frame)`,
  `fuel=FUEL_START`, color WHITE. Append to `self.ships`. Cap concurrent ships at 6.
- `_update_ships(dt_frames=1)`: for each ship, integrate position:
  `vx,vy = ship_velocity(ship.heading, ship.speed)`; `ship.x += vx; ship.y += vy`;
  wrap position around screen edges (x,y modulo 320/240); decrement `fuel -= 1`;
  append current pos to `trail` (keep last ~24 points). Do NOT check collisions here.
- `_check_collisions()`: for every pair of ships within `COLLIDE_DIST`, both are destroyed
  (remove from list), `lives -= 1`, spawn an explosion particle burst + floating text
  "CRASH" + screen shake. Return number of collisions.
- `_check_fuel()`: any ship with `fuel <= 0` is stranded (removed), `lives -= 1`,
  floating text "STRANDED". Return count.
- `_check_docking()`: any ship within `DOCK_RADIUS` of any bay AND `speed <= DOCK_SPEED_MAX`
  docks: removed, `score += dock_score`, `docked += 1`, particles + "DOCKED" text.
  `dock_score` module-level pure fn `dock_score(fuel_left, speed)` returning
  `100 + fuel_left // 60` (docking with more fuel left and slower = higher score).
  NOTE: only the SELECTED ship can dock (simulate the player aiming it) — actually allow
  any ship to dock if it meets conditions, since drift may naturally bring it in; this is
  fine and rewards good passive play. Keep it simple: any ship meeting conditions docks.
- `_steer_selected()`: called from `update()` with button states as arguments so it stays
  headless-testable. Signature: `_steer_selected(turn_left: bool, turn_right: bool,
  accel: bool, decel: bool)`. If `selected_index` valid: adjust `heading += TURN_RATE` /
  `-= TURN_RATE` (wrap to [0,360)), `speed = clamp(speed + THROTTLE_ACCEL, SPEED_MIN,
  SPEED_MAX)` or `- THROTTLE_ACCEL`. Update selected ship color to YELLOW; unselected WHITE.
- `_select_at(mx, my)`: set `selected_index` to the ship within `SHIP_RADIUS+6` of (mx,my),
  nearest if multiple, else -1 (deselect).
- `_check_game_over()`: `lives <= 0` -> `phase=GAME_OVER` (reason "ALL SHIPS LOST");
  `frame >= GAME_DURATION` -> `phase=GAME_OVER` (reason "TIME UP"). Persist best_score.

## Scoring
- Dock: `score += dock_score(fuel_left, speed)` (see above).
- Near-miss bonus: after `_check_collisions`, if any surviving ship is within
  `NEAR_MISS=14` of another surviving ship but not colliding, and hasn't been counted this
  pass, `near_misses += 1` and `score += 20` (once per pass, tracked via a small set of
  ship id pairs to avoid double count). Keep simple: count distinct near-miss pairs per frame,
  +20 each, cap contribution low (it's a small bonus).
- Final score = `score`; `best_score` persisted across runs.

## Difficulty escalation (1-2 knobs only)
- `spawn_interval` ramps 200f -> 50f (more ships).
- `spawn_speed` ramps 0.8 -> 2.2 (faster entry).
