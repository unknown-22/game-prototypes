## Genre & Theme
First **winemaking / fermentation** genre in the collection. The player runs a grape
press: crush grapes of the matching color, fill the fermentation tank, then BOTTLE the
wine to cash out a big score.

## THE MOST FUN MOMENT (one sentence)
「発酵タンクをギリギリまで満たしてコンボを伸ばし、溢れる寸前で瓶詰め(放電)して
一気に大得点を爆発させる瞬間が面白い」

## Core Loop (per action, ~1 second)
1. The **crusher color** auto-cycles through 4 colors (RED → LIME → DARK_BLUE → YELLOW).
2. Player CLICKS a grape whose color matches the crusher color.
3. Match → +1 juice into the tank, +1 combo, score += 10*combo; the grape respawns later.
4. Mismatch → HEAT+15, combo reset (grape stays).
5. When the tank is FULL (6 juice), further matches cause OVERFLOW (penalty).
6. Player presses **B** to BOTTLE: bank `juice × combo × 10` score, empty tank, reset combo.

## RISK / REWARD
- **Greedy**: keep crushing matching grapes to raise combo and fill the tank (max juice 6),
  bottle at the last moment for `6 × 6 × 10 = 360` points.
- **Safe**: bottle early (low juice × low combo = small payout).
- **Overflow risk**: crush while tank is full → OVERFLOW (HEAT+20, combo reset, juice stays 6,
  grape wasted). The auto-cycling color and clicking rhythm make over-crushing a real hazard.
- **Bottle cooldown**: after bottling, a 45-frame cooldown during which crushing is disabled
  (the crusher keeps cycling) — this is the "cooldown" resource from the source idea.

## Source Idea (game_idea_factory #1, Score 31.95)
Power-plant overload/discharge deckbuilder. Reinterpreted hooks:
- "combo + cooldown resources" → TANK CAPACITY (finite, forces periodic BOTTLE discharge) + bottle cooldown
- "effect multiplies and propagates across the whole board when chain condition met" → SUPER FERMENT yeast bloom (auto-crush bonus)
- "one color per turn" → crusher color constraint (must match crusher color)

## ESCALATION (functions of `self.frame`, linear over 60s = 3600 frames)

```python
def _cycle_interval(self) -> int:
    # 20 -> 12 frames over the game
    return max(12, 20 - (self.frame // 450))     # 20,19,...,12

def _respawn_delay(self) -> int:
    # 60 -> 25 frames over the game
    return max(25, 60 - (self.frame // 100))
```

## CORE LOGIC METHODS (pure, testable, NO pyxel input)

```python
def _handle_crush(self, index: int) -> str:
    """Handle a player click on grapes[index]. Returns 'match'|'overflow'|'mismatch'|'blocked'.
    - 'blocked' if self.bottle_cooldown > 0 or grape not alive or phase != PLAYING.
    - If self.juice >= TANK_MAX: OVERFLOW path -> heat += OVERFLOW_HEAT, combo = 0,
      kill grape (start respawn), return 'overflow'. (No juice/combo/score gain.)
    - Else if grape.color == crusher_color or self.super_mode: MATCH path ->
      juice += 1, combo += 1, score += BASE_SCORE * combo * (3 if super_mode else 1),
      kill grape (start respawn), trigger SUPER if combo >= SUPER_THRESHOLD,
      return 'match'.
    - Else: MISMATCH path -> heat += MISMATCH_HEAT, combo = 0, return 'mismatch'.
    """
```

Detailed ordering for `_handle_crush` (important for tests):
1. Guard: if phase != PLAYING → 'blocked'; if bottle_cooldown > 0 → 'blocked';
   if not (0 <= index < NUM_GRAPES) → 'blocked'; grape = self.grapes[index]; if not grape.alive → 'blocked'.
2. `matched = (grape.color == self.crusher_color) or self.super_mode`
3. If `self.juice >= TANK_MAX`:
   - `self.heat += OVERFLOW_HEAT`; `self.combo = 0`; kill grape (respawn); spawn particles+float text ("OVERFLOW!"); `_check_game_over()`; return 'overflow'.
4. If `matched`:
   - `self.juice += 1`; `self.combo += 1`;
   - `self.max_combo = max(self.max_combo, self.combo)`;
   - `mult = 3 if self.super_mode else 1`;
   - `self.score += BASE_SCORE * self.combo * mult`;
   - kill grape (respawn); spawn particles + float text (f"+{score}");
   - if (not self.super_mode) and self.combo >= SUPER_THRESHOLD: `self._activate_super()` then `self._super_bloom()`;
   - `_check_game_over()`; return 'match'.
5. Else (mismatch):
   - `self.heat += MISMATCH_HEAT`; `self.combo = 0`; spawn particles + float text ("WRONG!");
   - `_check_game_over()`; return 'mismatch'.

```python
def _bottle(self) -> int:
    """Discharge: bank juice*combo*10, empty tank, reset combo. Returns points gained.
    - If phase != PLAYING or bottle_cooldown > 0: return 0.
    - gained = self.juice * self.combo * BASE_SCORE
    - if gained > 0: self.score += gained; spawn float text "+{gained} BOTTLED!"
    - self.juice = 0; self.combo = 0; self.bottle_cooldown = BOTTLE_COOLDOWN
    - return gained
    """

def _activate_super(self) -> None:
    """self.super_mode = True; self.super_timer = SUPER_DURATION; spawn particles."""

def _super_bloom(self) -> None:
    """Yeast propagation (source hook 'multiply/propagate'): immediately auto-crush up to 2
    alive grapes at random. Each auto-crush follows the MATCH path (juice+1 if tank has room,
    combo+1, score += BASE_SCORE*combo*3) and kills the grape. If tank is already full, skip
    (do NOT trigger overflow). Use self._rng for grape selection. Must be deterministic when
    self._rng is seeded."""

def _check_game_over(self) -> None:
    """if self.heat >= HEAT_MAX: self.phase = Phase.GAME_OVER; update best_score."""

def _update_heat(self) -> None:
    """Decay heat over time. IMPORTANT ORDER: check game-over FIRST, then decay.
    if self.heat >= HEAT_MAX: self.phase = GAME_OVER; return
    if not self.super_mode: self.heat = max(0.0, self.heat - HEAT_DECAY)"""

def _update_timer(self) -> None:
    """self.frame += 1; if self.frame >= GAME_DURATION: self.phase = GAME_OVER; update best_score."""

def _kill_grape(self, index: int) -> None:
    """grape.alive = False; grape.respawn_timer = self._respawn_delay()"""

def _spawn_grape(self, index: int) -> None:
    """grapes[index] gets a new random color from COLORS (via self._rng), alive=True, respawn_timer=0."""

def _update_grapes(self) -> None:
    """For each not-alive grape: decrement respawn_timer; when <= 0 call _spawn_grape(index)."""

def _update_cycle(self) -> None:
    """Advance crusher color: decrement cycle_timer; when <= 0: crusher_index = (crusher_index+1) % 4,
    crusher_color = COLORS[crusher_index], cycle_timer = self._cycle_interval()."""

def _update_particles(self) -> None:
    """Move particles (x+=vx, y+=vy), decrement life, remove life<=0."""

def _update_float_texts(self) -> None:
    """y -= 0.5, decrement life, remove life<=0."""

def _update_super(self) -> None:
    """If super_mode: decrement super_timer; if <= 0: super_mode = False."""

def _update_bottle_cooldown(self) -> None:
    """if bottle_cooldown > 0: bottle_cooldown -= 1."""
```

## INPUT HANDLING (in `update()`, NOT testable directly)
- Title: `pyxel.btnp(pyxel.KEY_RETURN)` or `pyxel.btnp(pyxel.MOUSE_BUTTON_LEFT)` → `_init_state(); self.phase = Phase.PLAYING`.
- Playing: CLICK (`pyxel.btnp(pyxel.MOUSE_BUTTON_LEFT)`) → find grape index under cursor
  (distance from (mouse_x, mouse_y) to (grape.x, grape.y) <= GRAPE_RADIUS + 4) → call `self._handle_crush(index)`.
  - `pyxel.btnp(pyxel.KEY_B)` → `self._bottle()`.
- Game over: `pyxel.btnp(pyxel.KEY_RETURN)` or `pyxel.btnp(pyxel.KEY_R)` → `_init_state(); self.phase = Phase.PLAYING` (fast restart).
- Each frame in PLAYING: `_update_cycle(); _update_grapes(); _update_heat(); _update_timer();
  _update_super(); _update_bottle_cooldown(); _update_particles(); _update_float_texts();`
  (order matters: heat decay uses super_mode state; timer increments frame).
