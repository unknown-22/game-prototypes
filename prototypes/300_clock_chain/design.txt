# CLOCK CHAIN — Clock Repair / Watchmaker Prototype (prototype 300)

## Genre
Clock repair / watchmaking (untapped genre). Color-match COMBO chain with a "future hand as cost" (REWIND) mechanic.

## Experience hypothesis
"歯車の色が合わずCOMBOが途切れそうな瞬間、未来の手札(時間と次の歯車)を消費して巻き戻すか、素直にミスを受け入れるか迷う駆け引きが面白い"

## Screen
320x240, 60fps. Pyxel 2.x.

## Color constants (use these raw ints)
BLACK=0 NAVY=1 PURPLE=2 GREEN=3 BROWN=4 DARK_BLUE=5 LIGHT_BLUE=6 WHITE=7
RED=8 ORANGE=9 YELLOW=10 LIME=11 CYAN=12 GRAY=13 PINK=14 PEACH=15

Gear colors (4): RED=8, LIME=11, DARK_BLUE=5, YELLOW=10
GEAR_COLORS = [8, 11, 5, 10]  # index 0..3 maps to these

## Data model
- Particle dataclass: x: float, y: float, vx: float, vy: float, color: int, life: int
- FloatingText dataclass: text: str, x: float, y: float, color: int, life: int
- Queue of gears: `self.queue: list[int]` length QUEUE_LEN=6. queue[0]=ACTIVE gear,
  queue[1:4]="future hand" preview (NEXT), queue[4:]=pending.

## Phase enum
class Phase(Enum): TITLE, PLAYING, GAME_OVER

## Game class constants
SCREEN_W=320 SCREEN_H=240 FPS=60
QUEUE_LEN=6
GEAR_COLORS=[8, 11, 5, 10]  # RED, LIME, DARK_BLUE, YELLOW
CYCLE_INTERVAL_START=20 CYCLE_INTERVAL_END=12
HEAT_MISMATCH=15 HEAT_DECAY=0.02 HEAT_CAP=100
SUPER_THRESHOLD=4 SUPER_DURATION=300
REWIND_COST=120  # frames = 2 seconds
GAME_TIME=3600    # 60 seconds

## Instance state (all assigned in reset(); use self._rng = random.Random(42))
- phase = Phase.TITLE
- queue: list[int] = [self._rng.randint(0,3) for _ in range(QUEUE_LEN)]
- tool_color: int = 0
- cycle_timer: int = CYCLE_INTERVAL_START
- combo = 0; max_combo = 0; score = 0; best_score = 0
- heat: float = 0.0
- timer: int = GAME_TIME
- super_timer: int = 0
- elapsed: int = 0
- particles: list[Particle] = []
- floating_texts: list[FloatingText] = []
- shake: int = 0
- last_color: int | None = None

## Core methods (pure logic, NO pyxel input calls — headless testable)
- `_spawn_gear() -> int`: return self._rng.randint(0, 3)
- `_cycle_interval() -> int`: linear from START to END over GAME_TIME:
  int(CYCLE_INTERVAL_START + (CYCLE_INTERVAL_END - CYCLE_INTERVAL_START) * (elapsed / GAME_TIME))
- `_advance_tool_color()`: if cycle_timer <= 0: tool_color=(tool_color+1)%4; cycle_timer=self._cycle_interval()
  else cycle_timer -= 1. (Called once per update tick.)
- `_is_match(color: int) -> bool`: return super_timer > 0 or color == tool_color
- `_repair() -> bool`: attempt to repair queue[0]. Returns True on match, False on mismatch.
  Match: combo += 1; max_combo = max(max_combo, combo);
    mult = 3 if super_timer > 0 else 1; score += 10 * combo * mult;
    if combo >= SUPER_THRESHOLD and super_timer <= 0: super_timer = SUPER_DURATION
    last_color = queue[0]; pop queue[0]; append self._spawn_gear()
  Mismatch: heat += HEAT_MISMATCH; combo = 0; last_color = None; pop queue[0]; append self._spawn_gear()
  (Note: combo is set/reset on the CURRENT repair only; do NOT read last_color for matching —
   matching is done against tool_color via _is_match.)
- `_rewind() -> bool`: "future hand as cost" — skip the ACTIVE gear to preserve combo.
  Precondition: len(queue) >= 2 and super_timer <= 0. Returns False if precondition fails.
  Effect: timer -= REWIND_COST; pop queue[0] (discard); append self._spawn_gear().
  Combo and last_color PRESERVED. No heat change. Returns True.
- `_update_heat()`: CHECK FIRST — if heat >= HEAT_CAP: phase = GAME_OVER; return.
  Then if super_timer > 0: return (heat frozen). Else heat = max(0.0, heat - HEAT_DECAY).
  (Order matters: check threshold BEFORE decaying.)
- `_update_timer()`: timer -= 1; if timer <= 0: phase = GAME_OVER.
- `reset()`: reinitialize ALL state as listed above (assign self._rng = random.Random(42) FIRST).

## Scoring / super
Match scoring: combo incremented first, then score += 10 * combo * mult.
SUPER (rainbow): during super_timer>0, ANY color matches (_is_match always True), mult=3,
heat frozen (no decay, no mismatch possible). super_timer decremented in update() while > 0.

## REWIND decision (the "future hand as cost")
Front gear (queue[0]) does NOT match tool_color. Player chooses:
1. REPAIR anyway (mismatch): heat += 15, combo reset, gear consumed.
2. REWIND (R): timer -= 120 frames, gear consumed, combo PRESERVED, no heat.
So REWIND trades future time (and the skipped gear's potential score) to keep the combo alive.

## update() loop (PLAYING)
- elapsed += 1
- _advance_tool_color()
- if super_timer > 0: super_timer -= 1
- _update_timer(); _update_heat()
- update particles: life -= 1; x += vx; y += vy; drop if life <= 0
- update floating texts: life -= 1; drop if life <= 0
- if heat >= HEAT_CAP or timer <= 0: best_score = max(best_score, score)

## Input handling (ONLY in update(), never in testable methods)
- pyxel.btnp(pyxel.KEY_SPACE) OR pyxel.btnp(pyxel.MOUSE_BUTTON_LEFT) -> self._repair()
- pyxel.btnp(pyxel.KEY_R) -> self._rewind()
- pyxel.btnp(pyxel.KEY_RETURN): in TITLE -> reset(); phase=PLAYING. In GAME_OVER -> reset(); phase=PLAYING.

## draw() (PLAYING) — English text only, no CJK
- Clock face: pyxel.circb(160, 120, 90, WHITE) + tick marks at 12/3/6/9
- Clock hand: line from center (160,120) at angle based on remaining timer
- Gear queue along bottom: queue[0] large at (160, 200), queue[1..3] smaller at (205,225), (235,225), (265,225)
  labeled "NEXT"; pending queue[4:] as tiny dots. Fill with pyxel.circ using GEAR_COLORS[color].
- Tool color swatch top-left (small square, GEAR_COLORS[tool_color])
- HUD: "SCORE: n" top-left, "COMBO xN" top-center, HEAT bar vertical right side (color-coded),
  TIMER bar across top (width proportional to timer/GAME_TIME)
- particles (pyxel.pset or circ), floating text (pyxel.text)
- screen shake: if shake > 0: pyxel.camera(randint(-2,2), randint(-2,2)); shake -= 1 else pyxel.camera(0,0)

## 3 screens
TITLE: "CLOCK CHAIN" big text + "SPACE: REPAIR   R: REWIND" + "ENTER: START"
PLAYING: the game
GAME_OVER: "GAME OVER" + "SCORE: n" + "BEST: n" + "ENTER: RETRY"

## API constraints (MUST use these exact names)
- pyxel.tri (NOT pyxel.triangle)
- pyxel.KEY_RETURN (NOT pyxel.KEY_ENTER)
- pyxel.MOUSE_BUTTON_LEFT (NOT pyxel.MOUSE_LEFT_BUTTON)
- pyxel.mouse_wheel for scroll
- pyxel.circb = circle outline, pyxel.circ = filled circle, pyxel.line, pyxel.text, pyxel.pset
- NO non-ASCII characters anywhere in strings (Pyxel BDF lacks CJK glyphs)

## Headless testability
- `import pyxel` at top is fine (module imports headlessly; only calling Rust functions panics).
- Use `if __name__ == "__main__":` guard at bottom for pyxel.init + pyxel.run.
- Tests use `Game.__new__(Game)` to bypass __init__, pre-init ALL attributes reset() touches
  (or just call reset() which assigns everything), then call logic methods directly.
- NO pyxel.btn/btnp/mouse_*/play/camera calls inside any logic method (_repair, _rewind,
  _update_heat, _update_timer, _cycle_interval, _advance_tool_color, _spawn_gear).

## Requirements
- Single file main.py, Pyxel 2.x, 320x240, 60fps
- Dataclasses for Particle and FloatingText, typed with hints
- Phase machine (TITLE, PLAYING, GAME_OVER)
- Particle system + floating text + screen shake
- English-only text
