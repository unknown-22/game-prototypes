# 313 — HYDRA CHAIN

多頭のヒュドラと戦う、色合わせアーケードブラウラー。

## 体験仮説

「刃の色に合う頭をギリギリまで突いて育成してから、一気に同色の頭を連鎖切断して
コンボとスコアを爆発させるのが気持ちいい。ただし突きすぎるとヒュドラが激怒して
倍返しされる」という、育成と暴発の駆け引きを短時間で味わえるか。

## 実装したコアループ

- **頭（Head）**: 色（4色）と階層（tier 1–3）を持つ。画面上部の弧に並ぶ。
- **刃の色**: 20f→12f で自動巡回。
- **CUT（クリック）**: 刃の色が合う頭を切断 → スコア `10×combo×tier`。
  同色が連続して並ぶ頭はまとめて連鎖切断（合成圧縮 → 連鎖崩壊）。
- **STRIKE（SPACE）**: 頭を突いて tier を育てる（切断時の得点が増える）。
  ただし tier 3 の頭を突くと **ENRAGE**（激怒）: HEAT+20、頭は tier 1 に戻り、
  さらに頭が 1 本増える（ヒュドラは増殖する）＝「攻撃すると敵が強化される」逆転条件。
- **SUPER BLADE**: COMBO≥4 で発動（300f）。任意色一致・スコア 3 倍・HEAT 凍結。
- **HEAT**: 色違い切断 +15 / ENRAGE +20 / 自然減衰 -0.02/f。100 で「HYDRA RAMPAGE」。
- **60 秒タイマー**: 時間切れで「TIME UP」。
- 切断した頭は遅延後に tier 1 の新色で復活（ヒュドラは再生する）。

## 面白い瞬間（遊びの核）

「刃の色を待つ間に頭を突いて育て、色が合った瞬間に同色の頭をまとめて連鎖切断して
コンボが爆発する」瞬間と、突きすぎて ENRAGE が発火したときのヒヤリ。

## リスクとリターン

- 安全に今すぐ切る（低得点）か、突いて育ててから切る（高得点・ENRAGE リスク）か。
- 色が合うまで待つ間に、どの頭を育てておくか。

## 操作方法

| 入力 | 動作 |
|---|---|
| クリック | カーソル下の頭を CUT（色一致で切断） |
| SPACE | カーソル下の頭を STRIKE（tier 成長 / ENRAGE） |
| 1–4 | 刃の色を直接設定（デバッグ/練習用） |
| ENTER / SPACE | タイトル・ゲームオーバーで進行 |

## 次に改善するなら最初に触る点

- **STRIKE の利点をより明確に**: 現状 tier 成長の得点差（1倍/2倍/3倍）だけなので、
  「突いた頭は色が変わる」など切断の連鎖チャンスを広げる誘因を足すと判断が深くなる。
- **ENRAGE の可視化**: 現在はフラッシュ＋シェイクのみ。tier 3 の頭に警告マークを出すと
  失敗理由がより明確になる。
- **ベストスコアの永続化**: 現状プロセス内のみ（`hasattr` ガードでリスタート時は保持）。
